# backend/

.NET + PostgreSQL services for Zaghlol (SRS D-13, §7.29). Intentionally empty until Phase 5.

Scope: anonymous install registry, purchase verification & signed entitlements, store server notifications, merchant/category catalog sync, gold/FX price feed, feature flags, opt-in merchant contributions, optional Google/Apple account linking, operator tools.

Never stores user financial data (SRS BR-SYNC-03).
