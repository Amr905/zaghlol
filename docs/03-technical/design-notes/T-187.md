# T-187 design note: hide amounts in the app (C3, written by the implementer)

Requirement: D-67 / FR-HOME-06. One eye toggle masks every amount. This note is the inventory of every place an amount is built or rendered, and the one masking point they all go through.

## 1. Decision: mask where the string is built

Every amount on screen is a string made by `MoneyFormat.format` (`core/l10n/money_format.dart`) and then handed to `Text` or `ZMoneyText` (which receives text, never a number). So the masking point is `MoneyFormat.format`:

- New required named parameter `hidden`. When true it returns the same bidi-isolated shape with the digits replaced by the fixed mask `****` (`kAmountMask`): sign and currency kept (`-**** ج.م`, `EGP -****`), length independent of the size. Required, so a new call site cannot forget to decide (compile error).
- `hideAmountsProvider` (`core/settings`, a plain `Provider<bool>` over the new setting `hide_amounts.app`, default off, same encrypted `settings` table as the other `hide_amounts.*` keys, so no schema change). While the setting is still loading or unreadable it reads as hidden (fail closed), so a restart never flashes real numbers.
- Every presentation formatter reads the provider once and passes it down: `HomeFormat`, `TxnFmt`, `TransfersFmt`, bills `_Fmt`, budget `_money`, `chartMoney`, `chart_explain_l10n`, the Ask answer builder, wealth/zakah/money-tab/import-done/review helpers.
- `ZMoneyText` is defence in depth: if its text contains the mask (or `masked: true`), it shows the mask only (digits of the text replaced by `maskAmountText`), and its Semantics label is the l10n "amount hidden" instead of the glyphs. The old `kMaskedAmountFallback '•••'` and `maskedText` are removed.
- Percentages, counts, dates, weights (grams, coins) and category names stay visible: they are not amounts of money. Gold quantity in an explanation (`UnitAmountArg`) is an amount and is masked.

Other surfaces (OR with their own setting): notifications (`redactScheduled` / `prefs.hideAmounts`), home widget snapshot (`hideAmounts`), share cards (`showAmounts` forced off).

## 3. The eye button

`ZHideAmountsButton` in `core/ui/`: IconButton eye / eye-off, 48 dp target, Semantics label "Hide amounts" / "Show amounts" (l10n), haptic tick (`z_haptics`), writes `hide_amounts.app`. Placed beside the Home hero amount and in the app bar actions of Money, Insights/charts, transaction list and detail, budget, bills, card detail, wealth, zakah.

## 4. Lint (`tools/lints`)

New rule `no_unmasked_amount` (name-based, like the others):
- `MoneyFormat.format(...)` must pass `hidden:` and not the literal `false`; the formatter file itself is exempt.
- In `presentation/` and `application/` files: `NumberFormat(...)` and `.toStringAsFixed(` (amount formatting outside the shared formatter) fire; `.toCanonicalString()` fires outside edit-field prefill, which is annotated `// ignore: no_unmasked_amount - edit field, user is typing the number`.
Fixture and unit tests in `tools/lints/test`.

## 5. Tests

Unit: `MoneyFormat` hidden (ar/en, signs, currencies, digits modes, 3-decimal and 0-decimal currencies), `maskAmountText`, provider default and fail-closed, persistence round trip via the settings repository. Widget: eye toggles and announces; a walk over the top-level screens with masking on finds no digit in any amount widget; chart with masking on has no numeric text; Ask answer and explanation masked; notifications, widget snapshot and share card masked. Goldens (ar/en, light/dark): Home and one chart with masking on.
