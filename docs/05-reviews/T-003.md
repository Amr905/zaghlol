## Round 2 verification
**F1, implementation:**
- `Reject symlinks in the tracked tree` (`:172-179`) fails if any `git ls-files -s -- pubspec.lock app` entry has mode `120000`. This covers all of `app/`, which is wider than `app/test`.
- `Validate artifact` (`:180-214`):
  - Rejects anything in the artifact that is not a regular file or directory.
  - Allows `pubspec.lock` only when LOCK=true, and PNGs only when GOLDENS=true.
  - Rejects dot components.
  - Applies the whitelist regex.
  - Enforces the 200 KB and 2 MB caps and the PNG magic bytes.
  - Uses `while … done < <(find …)`, which is not a pipeline, so `exit 1` ends the step.
- `Copy` (`:215-244`) checks that the lexically normalized destination is inside the workspace and outside `.git`. It also rejects a symlink in any path component and requires the resolved path to equal the normalized one. It then copies with `cp --remove-destination` and `chmod 0644`.
- `Commit` runs git with `-c core.hooksPath=/dev/null -c core.fsmonitor=false`. Command-line config overrides repo config.
- Checkout uses `persist-credentials: false`. The token reaches only the push, through an `env:` value and `-c http.extraheader`. The base64 form is masked.
- With these changes, the "runs no repo code" invariant now holds.

**F1, proofs:**
- Proof A (42209342928, job 127864092973): `::error::tracked symlink(s) under pubspec.lock/app: pubspec.lock`.
- Proof B (42209963798, job 127866165160): `… app/test/goldens`.
- In both runs `regenerate` succeeded and `commit` failed at the first guard, before any download was used or any copy was made.
- The deviation (pointing the symlink at a tracked file instead of `.git/config`) does not weaken the proof. The guard keys on the index mode `120000` and never looks at the link target, so it rejects a link to `.git/config` the same way.
- The first attempt failed in `regenerate` only because pub get wrote through the link. That is incidental and not a control, so correctly it was not relied on.
- Proofs A and B together cover both attack shapes: a file symlink (the lock) and a directory symlink (the goldens directory). **Sufficient.**

**F2:** the regex checks match real pub output. The hardened `commit` validated the real lockfile and printed "Nothing changed" in run 42207136110. The README now carries the reviewer note. The residual gap is the flow-style bypass, R2-N1 (nit).

**F3:**
- The Gradle output goes through `tee` under `set -o pipefail`, so a Gradle failure still fails the step.
- The guard requires an executed `> Task :app:testDevNoSmsDebugUnitTest` line (no suffix such as NO-SOURCE or UP-TO-DATE) and at least one `<testcase` in `app/build/app/test-results/…`. That path is correct for Flutter's redirected buildDir.
- The report upload path is fixed: red run 42211250792 uploaded 6 files.
- All four red and no-test proofs fail for the expected reason (see the AC table).
- This also confirms the round-1 concern: before the fix, an empty Kotlin test directory gave NO-SOURCE and a green job.

**F5:** concurrency is now set on the `regenerate` and `commit` jobs. Skipped jobs never enter the group.

**F6:** the dot-component rejection is at `:204`.

**F7:** all 6 app-ci checkouts and `regenerate` use `persist-credentials: false`.

**F10:** the `static` step compares the semver values from both files and fails if either is empty or they differ.

**Regressions:**
