## Findings

### M-1 minor: cold-load budget is 3x looser than the AC
`packages/zaghlol_parsing/test/registry/registry_loader_test.dart:410-411`. Cold measured 45 ms, so the AC is met cold. The test asserts `best < 150` and `first < 450`. Change: assert `first < 150` (or at least 300) so a cold regression fails; keep the best-of-3 as the stable check. Best-of-3 alone would not have been acceptable as the only gate.

### M-2 minor: folded-capture residual contradicts the design note
`template_extractor.dart:181-183`. `counterparty`, `ref`, `ipa`, `phone` come from the folded (lower-cased, alef/ya/ta-marbuta-folded) body. The design note says "display text is never taken from folded input except the merchant", which is false for `counterparty` (a person's name shown to the user). English names show in lower case, Arabic names with folded letters. No fixture covers a counterparty. Not a T-032 major: the extractor is internal to the lint, nothing is displayed yet, and display mapping belongs to T-033. Required: (a) correct the design note/doc sentence now to state the residual; (b) T-033 follow-up to extract display captures from the original text (map folded offsets back, or re-match on a length-preserving fold) and add a fixture with an Arabic counterparty. Must be done before any UI shows counterparty.

### M-3 minor: ReDoS heuristic gaps
`regex_safety.dart:~120-135`. Probed: `(a+){1,50}b`, `(a|aa)+b`, `(a|ab)*c`, `(?:a|a?)+b` return no problem. Overlapping alternatives are documented; bounded-repeat of a group with an inner unbounded quantifier is not. Change: flag a repeating group (any `repeats`, not only unbounded) containing an unbounded quantifier when the upper bound is above a small limit (for example 3); treat `x|x?` as ambiguous. Also add a runtime guard in the fixture runner: lint fails if a template takes over N ms on any fixture or on a long adversarial body. The doc already states the heuristic is not a proof.

### M-4 nit: heuristic is hand-rolled
Parser is ~230 lines of index walking; the `closed`/`closedGroup` placeholder (`_Group(isRoot: true)` allocated each loop iteration) is awkward. Hoist or make nullable.
