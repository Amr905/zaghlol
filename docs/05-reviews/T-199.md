### Checked and correct
- **Anchor and tie:** the newer instant wins and a tie goes to the reported figure. A figure in another currency is ignored. For a liability, `limit - available` is floored at 0. For an asset account, `available` is used only when there is no `balance`, and it carries its own label (Lead decision 2).
- **Counted transactions:** `deleted_at IS NULL`, `status='posted'`, own account and currency, `occurred_at` strictly after the anchor. Ingestion records `as_of` equal to the transaction's `occurred_at`, so the message that carries the balance is never added twice. Manual entries for today use the current time.
- **Signs:** income, refund and transfer_in add; expense, fee and transfer_out subtract. These are all six directions the schema allows. A liability uses the opposite sign: purchase, fee and cash advance raise the owed amount; card payment and refund lower it. `is_internal` is correctly not used as a filter. Offset links and splits do not touch balances.
- **Merged accounts** are skipped, and the user balance moves with a merge inside the same transaction (newer instant wins). **Hidden accounts** count.
- **Installments** are skipped when their own card already has a counted owed amount in that currency. Gold stays in grams/coins ×1000 and is never added to money. Overflow throws code-only errors. Nothing is logged.
- **Opening-balance JSON:** typed and validated per field. Currency and range go through `Money.tryFromStorage`, entries are capped, bad text is read as empty (never echoed), and output is written with `jsonEncode`, so nothing can be injected. The setting lives in the `settings` table, which backup and restore already carry.
- **Gating** matches FR-WLT-01: free users see accounts only, with credit and BNPL as liabilities. `compute` (snapshots) still includes everything. The Money tab figure now subtracts cards, which moves it towards BR-WLT-01.
- **Masking and a11y:** every amount goes through `MoneyFormat(hidden:)`, gold is masked too, labels go through `a11yAmounts`, targets are 48 dp, and tests cover the hidden state.
