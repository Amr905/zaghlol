## Judgment on declared deviations
- **Single-pass normalizer, three levels:** accepted. The levels are layered by a flag, and the fuzz tests check idempotence and the absence of removed code points. The design's concern about blurring levels is met by three separate public functions.
- **`$` set {USD,CAD,AUD,NZD,SGD,HKD,MXN}, default USD; `﷼` set {SAR,QAR,OMR,YER,IRR}, no default:** accepted. It is a reasonable, conservative extension of the design note. See finding 1 for the one practical consequence.
- **Unambiguous marker beats fallback:** accepted. The marker is explicit text in the message, so the fallback is only a guess. This is the safer reading under "never silently converted".
- **Multiple numbers or markers give `malformedAmount`:** accepted. Failing is safer than guessing which number is the amount.
- **Known unhandled (space grouping, trailing stop, `¥`):** acceptable for T-013. `¥` is correctly left out because it is ambiguous (JPY/CNY) with no safe default. Findings 2 and 6 track the rest.
