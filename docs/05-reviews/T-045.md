## Judgement on the deviations
- **One global default cash (not per currency):** accepted. FR-ACC-03 says "a default Cash account", the T-017 partial index is global, and per-currency cash is a balance row of the same account. The label is passed in, so no user-facing string in data.
- **Institution-only account with id `inst:<code>`:** accepted. A NULL last4 is outside the unique index, so the PK is the arbiter. A user-made institution-only account with another id is found, not duplicated (stated residual).
- **Merged cards resolve to the merge target:** accepted and tested (`a merged-away card resolves to its merge target`, and the chain test). The partial index excludes merged rows, so the same inst+last4 cannot reappear as a live row.
- **`inferAccountKind` takes the event wire string:** accepted (no app-to-parsing dependency); the mapping stays with T-046. See F-4.
- **`totalsByCurrency` excludes credit/BNPL, includes hidden:** accepted (D-69; a credit "balance" is debt or limit). Sums are per currency with `Money +`, never converted.

## Other checks (no finding)
