| 204 / 401 / 503 rule (§1 step 3) | After auth, unreadable body, bad envelope, stale, wrong subscription, wrong package, bad type/token → 204 + `ignored_*`. Only a `DbException` anywhere in the inner chain → 503 + `Retry-After: 10`. See F-6 for non-DB exceptions. |
| Idempotency by `messageId` | `ON CONFLICT (store, external_id) DO NOTHING`; `messageId` pattern excludes `:`, so it can't collide with `voided:`/`sweep:` keys; digest = SHA-256 of decoded `data`.
