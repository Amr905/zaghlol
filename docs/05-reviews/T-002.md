## Deviation from the task text
The task says "custom_lint plugin". The branch ships `tools/lints`, a standalone `package:analyzer` syntax-only checker run as `dart run bin/zaghlol_lints.dart <roots>` in the `static` job, plus `dart test` for it. The README documents the reason (custom_lint 0.8.1 loads but never calls `run` on Dart 3.13; a deliberate violation passed). The intent is preserved: all four rules exist, fire on fixtures, are silent on compliant code, and gate CI (exit 1 fails the job; the log is echoed and annotated). I accept the deviation. Cost: name-based matching, and violations do not show in the IDE or in `flutter analyze` (documented in `.github/workflows/README.md`).
