## Verification notes
- **Layering is correct.** Domain → Application → Infrastructure → Api/Workers. Ops stands alone.
- **Problem Details cannot leak exceptions.** All errors go through one `IExceptionHandler`. 5xx responses have a fixed title and no detail or instance. The tests assert that no exception text or stack trace appears.
- **CI enforcement is real.** No step uses `continue-on-error`. NuGet audit warnings fail the build. A separate `--vulnerable` job runs. Trivy runs with `--exit-code 1`. The workflow has only `permissions: contents: read`.
- **Secrets are local-dev only.** The only credential is `POSTGRES_PASSWORD=zaghlol_dev_only`; it can be overridden, postgres binds to loopback, and `.env` is git-ignored.
- **Accepted deviations:** one image for both API and worker (per ADR-022), and healthchecks via `dotnet <dll> --healthcheck` (the chiseled image has no shell).
