## Judgement on the requested points
- **Stages vs spec.** Order (fold once, size cap, institution, drop, language-first template order, first match wins, typed extraction, template direction, merchant cleaning, confidence) matches parsing-engine §1 and §4. A template with unreadable amount or currency is skipped and a later one tried; the first failure is returned if none succeeds: sound.
- **Never guessing.** Absent or non-participating groups are null. `last4` borrowing from declared patterns is skipped when the template owns a `last4` group. Unknown currency marker is fatal, not defaulted. OK.
- **Confidence / needsReview.** Integer arithmetic, floor per step, reasons de-duplicated and ordered, clamp 0..1000, threshold 850 permille, `needsReview` strictly below it. 950 x 0.9 = 855 stays unreviewed, tested at the edge. Correct.
- **Display captures.** `_uniqueOffset` is correct: the real capture is one occurrence inside the match region, so if exactly one occurrence exists it is the capture (overlapping occurrences are counted, so it is conservative). Two or more gives the folded capture, never a wrong span. Tested (`template_extractor_test` "the same text twice"). Residual is documented (see M-4).
- **ReDoS.** The new heuristic rules are tested both ways (flag and accept cases). The adversarial probe stops at the first size over the limit and the slow-pattern test shows the static heuristic misses what the probe catches. The exponential residual is honestly documented (see M-2, M-3).
- **No message text in results/errors.** `ParseDropped` and `ParseUnrecognized` hold enums and registry ids only; `internalError` catch keeps nothing. Sentinel and "only registry ids" tests are meaningful. Lint issues carry path and field name only.
- **Benchmark validity.** Warm-up, mixed fixtures plus two worst-case misses, asserts more than half parsed so it cannot pass by returning early. Valid.
- **Fixtures.** 43 files (>= 40 asserted), synthetic: `@instapay` addresses and 01x numbers are made-up, Arabic names generic, no real bodies. Variety is good (digits, tatweel, thousands, JPY exponent 0, year wrap, stale date).
- **T-032 minors.** M-1 (`first < 150`), M-3 (bounded-repeat, `x|x?`, prefix alternatives, runtime guard), M-4 (nullable `closed`) done; M-2 done via original-text captures.
