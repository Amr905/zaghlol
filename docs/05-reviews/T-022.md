## Judgment on stated deviations
- **Ahem goldens (no font):** accepted as a minor (finding 1). Layout, RTL mirroring and colour are still covered. Glyph fidelity is not.
- **Forced Directionality in the harness:** accepted. `flutter_localizations` belongs to the l10n task. The harness forces direction from the locale, so RTL behaviour is exercised; `Locale('ar')` itself is not. Revisit when the l10n delegates land; the matrix should then drop the forced `Directionality`. Owner: the l10n task.
- **Rule-2 ancestor-walk narrowing not done:** accepted. The rule fires on any string literal in a widget-returning function, minus `isTechnicalString` and context allowances. This favours false positives and is safe. Revisit only if real code produces noise. Owner: T-002 follow-up, no deadline.
