# Mockup generator
Requires Python 3, Node + Playwright (Chromium). Put the fonts in `assets/` (segoeui.ttf, seguisb.ttf, segoeuib.ttf, SegoeIcons.ttf, seguiemj.ttf — or swap @font-face in base.css for IBM Plex Sans Arabic + Material Symbols).
    python3 s_screens.py && node render.js
Output: `out/*.png`.
