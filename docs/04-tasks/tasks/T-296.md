## Scope (artboard "2 · Empty states + review queue")
1. **Empty lists**: every list screen's empty state (transactions, bills/recurring, a card with no messages, accounts, budgets, goals, search with no results, review queue when empty) shows the `sleep` moment (~120 px), a short Egyptian line («مفيش فواتير لسه» style) and its existing primary action. Make one shared empty-state widget if none exists, else extend the existing one; list every screen you touched in the task file.
2. **Review list header** (`features/ingestion/presentation/review`): when items wait, a header card with the `detective` moment (~64 px), «{n} رسايل محتاجين نظرة» (plural ARB) and one helper line. Not shown when the list is empty (then the sleeping empty state).
3. Never two birds on one screen (if a screen already has the Home mascot slot or another bird, skip it and note it).
