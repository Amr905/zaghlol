## Description
The PO wants an eye icon beside the money so the app can be shown to friends without exposing any numbers. Today hide-amounts exists only for notifications (`hide_amounts.notifications`), the home-screen widget (`hide_amounts.widget`) and share cards; `ZMoneyText` has a `masked` flag that nothing app-wide drives, and many amounts are rendered as plain `Text` outside `ZMoneyText`.

## Technical details
- **Setting:** new `hide_amounts.app` (bool, default off, encrypted prefs like the others) and a `hideAmountsProvider`. Toggling is instant, no restart.
- **Toggle:** an eye / eye-off icon button beside the Home hero amount (as drawn on the design canvas), and the same icon in the top bar of Money, Insights, transaction list/detail, budget, bills, card detail and wealth screens. `aria`/Semantics label "إخفاء المبالغ / Hide amounts" and "إظهار المبالغ / Show amounts". Haptic tick on toggle.
- **One masking point:** route every amount through the shared money formatter / `ZMoneyText`. Inventory first: grep every place an amount string is built (formatters, `NumberFormat`, chart labels, Ask Zaghlol answers, explanation templates, CSV preview, budget progress text). Anything not going through the shared path is migrated. Add a repo lint (tools/lints) that flags amount formatting outside the shared formatter, so a new screen can't leak.
- **Mask format:** digits replaced by `****` (fixed length, so the length doesn't hint at size); sign and currency kept (`−**** ج.م`, `+**** EGP`); Arabic and English; bidi-isolated like today. Replace `kMaskedAmountFallback '•••'` with the new mask.
- **Charts:** keep bar heights, slices and lines (shapes only reveal proportions); hide axis values, data labels, tooltips and the numbers in "Explain this chart"; percentages may stay.
- **Ask Zaghlol / mascot messages / explanations:** templates render masked amounts.
- **Other surfaces:** while `hide_amounts.app` is on, notifications, widget and share cards also mask (OR with their own settings).
- **Not in scope:** hiding transaction names or merchants; app lock (exists).

## Acceptance criteria
1. One tap on the eye masks every amount on every screen (Home, lists, details, charts, budgets, bills, cards, wealth, Ask Zaghlol, explanations); a second tap shows them. A widget test walks every top-level screen with masking on and finds no digit in any amount widget.
2. The setting survives an app restart.
3. Charts with masking on show no numeric value anywhere (axes, labels, tooltips, explanation) but keep their shapes.
4. Notifications, the home widget and share cards are masked while it is on.
5. Goldens in `ar` and `en`, light and dark, for Home and one chart with masking on; RTL verified.
6. The new lint fails on an amount formatted outside the shared path; repo is clean under it.
7. No hard-coded strings; Semantics announce "amount hidden" instead of the masked glyphs.
