## Description
Zaghlol explains every chart with real numbers and one tip.

## Technical details
Rules choose salient fact + tip per chart; Gold adds previous-cycle comparison, projection and drivers; values always computed.

## Design note
Short note (builder, per SPRINT.md; copy deck §2.0.1 and §2.4 are the spec):

- Location: `app/lib/features/insights/domain/explanations.dart`, next to `chart_models.dart` (its inputs live in the app, so the task's `packages/zaghlol_domain` path was not used).
- The engine is pure Dart and returns `ExplanationLine(key, typedArgs)`, never text. `key.l10nKey` is the generated l10n member name from T-087 (`insightsExplain<Chart><Part>`, `insightsDeepProjection`, `insightsDeepDrivers`). Args are `MoneyArg`, `PercentArg` (bp), `CategoryArg`, `NameArg`, `WeekdayArg`, `HourArg`, `MonthArg`, `UnitAmountArg`, `SelectArg`. T-108 renders each line with the matching `AppLocalizations` call, so numbers are the query results and digits/currency follow the locale.
- `explainChart(input, tier, {context})`. Basic tier = fact + tip and never reads `previous*` inputs. Deep tier = fact + deep + deep tip, plus projection (charts 1, 2, 3, 5, 7, only with a budget) and drivers (three merchants whose spend moved). The caller picks the tier with `tierFor(isGold:)` from the T-119 entitlement.
- A sentence whose values can't be computed is dropped whole; if the basic fact can't be computed the explanation is empty and the screen shows the needs-data state (`needsDataFor`).
- Rules: salient fact = largest slice / peak day / biggest rise; `trend` is `other` within 1% of the base; tips size a step at a tenth of the figure (a quarter for merchants, half the surplus for cash flow); yearly = per-cycle x 12 (x 52 for weekdays).
- Q-20: no disclaimer line is emitted. Q-24: no halal wording (none in these keys). Q-25: tips never name an essential category (`ExplainContext.essentialCategoryIds`, default seed set) or a protected merchant; facts may still name them.

## Builder notes (T-106)
- Missing l10n keys: none. All 50 keys (48 `insightsExplain*` + `insightsDeepProjection` + `insightsDeepDrivers`) exist in both ARBs; a test checks this and that every arg is a declared placeholder.
- The renderer (T-108) must supply: category names from ids, `common_unit_visits` for visits, `common_assetType_*` names, weekday and hour formatting.
- Open: the essential category id set (`defaultEssentialCategoryIds`) is a guess at catalog codes; T-108 should pass the catalog's real essential ids (Q-25 list: rent, bills, groceries, health, education, fees, debt, work transport).
- Open: merchants carry no category in `MerchantSpend`, so Q-25 is applied to merchant tips through `protectedMerchantNorms` supplied by the caller.
