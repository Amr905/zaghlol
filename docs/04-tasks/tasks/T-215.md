## Request (PO, 2026-11-23)
"Also add the other animations." The generated `zaghlol.riv` (T-212) has all 15 moods; the app triggers only 11 (`tourGuide, proud, shocked, detective, professor, listening, thinking, counting, saved, oops, sleep`).

## Description
Wire the remaining moments from `docs/02-design/08-mascot-motion-and-bank-logos.md` §1 (table and rules):
- **Payday** (`payday`): when a salary/income is detected for a new payday cycle, once per payday (store the last payday celebrated in encrypted settings).
- **Tap the bird** (`tap`): tapping Zaghlol anywhere he shows plays the tap mood plus a new funny line each time (rotate through a small set of Egyptian lines in ARB; no repeats back to back).
- **Pull to refresh** (`pull`): pulling down on Home and on lists that already have pull-to-refresh shows the bird; uses the existing refresh indicators, no new refresh behaviour.
- **Reading messages** (`scanning`): during the historical SMS scan and card re-scan, instead of whatever mood runs there now (check; `detective` may be used).
- **Talk** (`talk` input): beak moves while a Zaghlol bubble line is being revealed/spoken, if the bubble animates text; otherwise for the first 1.2 s after a new line appears.
Rules from the doc apply: one bird per screen, never delays a result or covers a button, reduce motion shows the still pose plus the line.

## Acceptance criteria
1. Each moment triggers in the right place, once where the doc says once, and loops only while work runs.
2. Payday fires at most once per payday cycle, survives restarts, never fires on the first import of historical messages (no celebration for old salaries).
3. Tap lines rotate without back-to-back repeats; strings in ARB + copy deck (Egyptian colloquial, en too).
4. Reduce motion: no motion, still pose plus line.
5. Widget tests per moment (the interim/still mascot is what tests render; assert the requested `ZaghlolMoment` and `talk` on the avatar); goldens only if layouts change (`[regen-goldens]` in the last commit; never generate locally).
6. `dart analyze`, `dart format`, mascot + touched feature tests green.
