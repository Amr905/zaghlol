## Build notes (T-085)
- Entry points for the shell: `startAddCard` (Money `onAdd`), `openEditCard` (Money `onOpenAccount` / hidden rows) in `edit_card/add_card_flow.dart`. Wiring them into the router is the shell's job.
- Create = `AccountsRepository.resolve` + `update` (limit, due day), then `RecurringRepository.syncCardDues()` (T-096). Merge = `AccountsRepository.merge` (one DB transaction: transactions, recurring items, balances per currency; pairs untouched).
- Capture toggles on a new card need `cardCapturePortProvider` (a `CardCapturePort` over `IgnoreRulesService.add`, T-078). No provider for the service exists yet, so the toggles stay hidden until the shell overrides it.
- Missing l10n keys (not added, per sprint rule): none blocking. Reused `commonAccountType*`, `commonChannel*Short`, `commonValidation*`. Wanted but absent: a "Foreign" currency picker label; "cash" is not creatable. The merge-picker empty state reuses `accountsMergeErrorSelf` (no dedicated "no other card" string).
- Deviations: last-4 is required only for credit/debit (wallet, multi-currency and BNPL may be institution-only); "Also copy capture settings" (`accountsMergeCopyCapture`) is not offered (no repository support); name/limit/due-day edit only: bank, last-4 and currency are read-only in edit (the repository's `AccountEdit` cannot change them); multi-currency balances list (`accountsEditBalances`) not built.
