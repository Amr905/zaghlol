## Description
Wire `LlmAskFlow` states into S-50: 300-char limit with counter from 250; quota counter at the input's end edge (tappable info sheet, "—" unknown); Send ↔ Stop; typing row with `thinking` mood (still pose under reduce motion); clarification bubble with chips and "not sent"; offline, timeout/error + Try again, slow down (no retry), integrity (Try again), paused (`sleep`, counter hidden), last-question note, exhausted Free (Gold hint + "See Gold" → S-68) and Gold (reset date). Answers render through an `llmAnswerViewBuilder` provider (T-347 supplies the real views). Flag off → S-50 unchanged.

## Acceptance criteria
1. Widget test per state of the UX §1 table with a fake flow, in ar and en.
2. Goldens: idle, sending, clarify, error, paused, exhausted Free, exhausted Gold — ar/en, light/dark; 130 % for idle (counter on its own line).
3. Flag off: S-50 golden identical to the current one.
4. Screen reader: status changes are polite live-region announcements; counter label `quota_remainingA11y`; Send/Stop 48 dp.
5. "See Gold" opens S-68; the paywall counter (FR-GOLD-05) increments only on that tap.
