## Design note (implementer, 2026-11-14; sprint rule: the implementer writes it)
**Scope.** `app/ios/Runner/Guard/` holds a line-for-line Swift port of the Dart/Kotlin Guard: `GuardTypes` (channels, reasons, decision, policy), `TextFold` (`foldKey`/`foldKeyLines`/Dart trim over UTF-16 units), `StrictJson` (same strict reader as Kotlin), `GuardConfig` (base v4 + user v1 reader, caps, error codes, modes), `CaptureGuard` (steps 0-5 incl. the FU-121 phone-number filter), `SenderRateLimiter`, `GuardUserCipher` / `GuardUserConfigStore` (AES-256-GCM, AAD `zaghlol.guard.v1|user`, tmp + fsync + rename, file kept when unreadable), `GuardBaseSource` (bundle path + App Group mirror), `GuardRuntime` (lazy load, caching rules and `writeUser` as in T-038 section 4-6).
**Decisions.**
1. The bundled base part replaces the old "compiled-in fallback senders" (T-035 split, T-038): an unreadable base is mode `invalid` (every message `config_invalid`), retried on the next message. No compiled-in list.
2. Regexes: `NSRegularExpression(pattern:options: [])`, search semantics via `firstMatch` over the full UTF-16 range (platform-channels 1.1). Folded text and every key are compared as `[UInt16]`, never as Swift `String` (`==` and `contains` use canonical equivalence, Dart/Kotlin do not). The phone-number shape is a loop, not a regex.
3. Keys: the user part is encrypted with the Keychain spool key `spool_key_v1` through the T-015 `DbKeyKeychain` slot (account `spool_key_v1`; `AfterFirstUnlockThisDeviceOnly`, never synchronizable, no overwrite of an unusable item). A read never creates a key; a missing key for an existing file is "unreadable" (kept, not deleted); a Keychain error is transient (not cached). T-062 owns the shared access group and the key-recreation policy; until the App Group entitlement exists the item is in the app's own group.
4. Not wired yet: the Pigeon `writeGuardConfig` host and the intents (T-062/T-063) call `GuardRuntime.writeUser` and `GuardRuntime.decide(channel:source:body:)` (typed `IosGuardChannel`: `shortcutMessage`, `applePay`; `share` skips the Guard by design). `ZaghlolDirectories.appGroupIdentifier` is still nil, so `GuardBaseSource.mirror` is implemented and tested but not called.
5. Never logging: no print/NSLog/os_log in the directory (a test scans the sources); every `description` prints mode, reason or kind only; error types carry codes and JSON paths.
6. The T-009 spike (`Runner/Spike`, `IosIntentSpikeTests`, the `ios-intent-spike` CI job) is **kept**: this task has no engine or spool, so it does not replace it; T-062/T-063 take the headless-run harness from it and delete it. The task file does not ask for deletion here.
**Known, accepted difference.** A lone-surrogate JSON escape in a config becomes U+FFFD in a Swift `String` (Dart and Kotlin keep it); no valid config contains one.
**Rejected.** `JSONSerialization` (lenient on duplicates and numbers), `String`-keyed dictionaries for folded keys, code-generating Swift from Dart.
