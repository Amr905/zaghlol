## Description
Turn an `LlmAnswer` (T-342) into display text: use the validated LLM template only for single-currency data and what-if answers; otherwise the app template for the plan (INVEST, SUGGEST, REFUSE, FALLBACK, multi-currency always app-owned). Fill blanks through `MoneyFormat` (C-04: masked `****` with hide amounts, grams hidden), digits per the digits setting, card last-4 always Western LTR, percentages kept. Answer language = app language.

## Acceptance criteria
1. The six UX §5 examples render exactly in ar and en (string tests).
2. An LLM template for PL-INVEST or a multi-currency answer is ignored in favour of the app template.
3. Hide amounts on: every amount blank masked, grams hidden, percentages visible.
4. Arabic-Indic digits when the setting says so; card digits Western in both.
5. No hard-coded user-facing strings (all from ARB).
