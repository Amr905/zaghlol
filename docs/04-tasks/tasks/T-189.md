## Description
Lead review of the current charts (goldens `charts_*`, `gold_charts_*`, `chart_detail_*` and code, 2026-11-19):
- **No interaction:** touch is disabled on every chart (`BarTouchData(enabled: false)`, `PieTouchData(enabled: false)`, `LineTouchData(enabled: false)`), so values can't be read and nothing drills down.
- **No scale:** no value axis and no gridlines (`FlGridData(show: false)`, empty `leftTitles`), so bars can't be compared by value.
- **One long scroll:** all 12 charts stack as equal cards with no summary on top; the most useful ones aren't first.
- **Crowded labels:** cycle labels under the cash-flow bars run together.
- **Thin data:** with little history the line charts (net worth, gold) are near-flat 2-point lines and the installment timeline is almost empty; there is no "not enough data yet" state.
- **No comparison:** nothing says whether this period is better or worse than the last.

Research (finance apps and chart UX, 2026-11-19): users expect a period picker with relative presets (Monarch), month-over-month and year-over-year category comparison (Copilot), the previous period overlaid on the same chart plus category-level change (Finny), a per-category % change vs the previous period and average daily spend (Money Lover), a savings rate for the period (Lunch Money), and tap / press-and-drag scrub tooltips on mobile (SAP Fiori). Touch targets 44 pt iOS / 48 dp Android.

## Technical details
1. **UX note + mockups (Opus `ux-designer`, PO sign-off before build):** the charts screen top-to-bottom: summary strip (spent, earned, saved, savings rate, each with % vs previous period), then charts ordered by usefulness (cash flow, category donut, top merchants, budget, month vs average, then the rest), with the period chip from T-188.
2. **Interaction:** enable touch on bar/line/pie; tap shows a value bubble, press-and-drag scrubs; tap a bar / slice / merchant row opens the transactions list pre-filtered to that category / merchant / period.
3. **Scale:** a light value axis (3–4 gridlines, compact labels: ١٫٢ألف / 1.2K) where values are compared; data labels on donut legend.
4. **Comparison:** totals and category rows show the change vs the previous period of the same length; cash flow can overlay the previous period as a faint series.
5. **Clarity:** top 5 + "Other" in donut and merchants; label thinning on crowded x-axes; per-chart empty / thin-data state with a Zaghlol line ("محتاج شهرين كمان عشان الرسم ده يبان").
6. **Accessibility:** each chart gets a text summary for screen readers; colour is never the only cue.
7. Respects T-187 hidden-amounts mode (no values shown when on).

## Builder note (T-189, Sonnet/Opus build, 2026-11-22)
Built to the approved mockups (`docs/02-design/mockups/charts/`). Domain maths is pure Dart in `domain/chart_summary.dart` (summary vs previous period per currency, top-5 + Other with change chips, Zaghlol line choice, axis steps, compact labels); everything uses `ResolvedChartPeriod.previous` (same elapsed days while the period is open). UI: `charts/chart_overview.dart` (strip, change chip, one-liner), `chart_drill.dart` (tap-through + header), `chart_thin.dart` (thin-data states), reworked `chart_bodies.dart` (cash flow axis/hatch/bubble, donut selection/legend/chips, places with counts) and touch on the Gold lines/bars. Charts screen order: strip, cash flow, donut, places, budget, month vs average, then «كل الرسوم (١٢)» (the other eight are not built, so not queried, until opened: NFR-PERF-04). «شهر»/"month" replaces «دورة»/"cycle" in the chart and period-picker strings only (the shared `commonPeriod*` keys used by the transactions list are untouched; the chart picker uses new `insightsChartsPreset*` keys).

Drill-down: `openChartDrill` sets `txnListFilterProvider` (custom period, category ids or merchant, expense type, currency) while the list route is open and restores the previous filter on pop; the list got a merchant chip (`TxnListFilter.merchantNorm`, `TransactionFilter.merchantNorm`, `TxnQuery.merchantNorm`), a category-name chip label for a single category and an optional `header` slot (insights fills it with total, count and change).

Deviations: (1) the daily "صرفك يوم بيوم" line of mockup 2 is not a new chart; press-and-drag scrub with a value bubble is on the existing line charts (burn rate, net worth, inflation). (2) The net-worth thin state does not show the current number (the query returns no value below its minimum); it shows the Zaghlol line only. (3) "Other" in the merchants list is not added (mockup 1 shows five places only); Free's limit is already 5. (4) The two Gold bar charts (week pattern, installments) use fl_chart's own tooltip on tap; the Free bars, the donut and the lines use a widget bubble (testable and readable by screen readers). (5) Calendar-month presets and payday-cycle presets both read "this month / last month" in the picker, as in the mockup; their subtitle ranges tell them apart. (6) The shared mascot widget is `ZaghlolAvatar` (via `ZMascotBubble`), not `ZaghlolAnimatedAvatar`; it ignores pointers and shows the still pose under reduce motion.

Goldens that change (not regenerated): `charts_golden_test.dart`, `gold_charts_golden_test.dart`, `chart_detail_golden_test.dart` (titles, summary strip, axis, wording), `chart_period_golden_test.dart` (preset names), `insights_shell_golden_test.dart`. New goldens for the strip, drill-down header, thin-data and hidden states are still to be added when the others are regenerated.
