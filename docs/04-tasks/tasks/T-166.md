## Description
Return to first-launch state with nothing financial left behind, while keeping the iPhone seat keys that let Gold come back without a move.

## Technical details
- Confirm; on **Android**, while this install holds a seat, the confirmation warns first that restoring afterwards counts as this month's move, with `nextMoveAt` when a cooldown runs (data from T-145; copy from T-028).
- Cancel jobs; close DB; delete DB (including tokens, trusted-time state and `supportNotice` in `secure_state`), spool, temp, widget snapshot; delete Keystore/Keychain items **except the iOS seat keys**: call `SeatKeyHostApi.rotateForNewInstall()` so the current key becomes an "earlier" key (D-55, R4-8). Delete the App Attest `keyId` item (the next install re-attests).
- `DELETE /v1/installs/me` best effort (one retry); restart.
