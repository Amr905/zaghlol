## Scope
1. A row holding several label–value pairs is split into segments at each label; the total label takes the amount in **its own** segment (after it, or before it in RTL order), and a skip word elsewhere on the row doesn't hide it. A segment that is only a skip label is still skipped.
2. `المتبقي`/`المتبقى`/`remaining`/`balance due` (outstanding, often negative) are skip lines, never the total; a negative number is never the total.
3. Merchant: never a line that is only a city (`القاهرة`, `الجيزة`, `الاسكندرية`…), a branch line (`فرع …`, `branch …`), digits/hotline, a seller/cashier/customer field (`البائع`, `العميل`, `الكاشير`, `cashier`, `seller`, `customer`), a delivery/address/phone field, or a table header (`الصنف`, `الكمية`, `السعر`, `item`, `qty`, `price`). If nothing is left, merchant stays empty (the user types it).
4. Fixtures in `packages/zaghlol_parsing/test/ocr/pharmacy/`: the PO layout in the four orders (Lead's synthetic text is in this task's "Probe text" below), each expecting 573.00 EGP via the label path (`ocr.receipt.generic`, confidence 600 or the column 550), date 2026-11-13, merchant empty.
