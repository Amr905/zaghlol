## Description
Optional, clearly labelled combined totals.

## Technical details
Integer conversion with rate_e9, banker's rounding at end; target currency selectable; returns rate date & excluded currencies; off by default.

## Design note
Short note (implementer; none existed). Code: `app/lib/features/wealth/domain/approx_view.dart` (pure) and `.../data/approx_view_providers.dart`. It sits in the app, not `zaghlol_domain`, because it reuses T-112's `FxTable.convertApprox` (rate_e9 integers, one half-even rounding per converted currency); the converted amounts and the target-currency amount are then summed exactly. Off = `ApproxViewOff` (no figure type exists, rates not read). On = `ApproxViewOn` with a nullable `ApproxFigure` (not a `Money`), `excluded` currencies (non-zero total, no rate path; zero totals need none), `rateAsOfMs` = oldest rate used, `stale`, and `approximate` (false when only the target currency is present). Nothing is stored. Overflow throws `MoneyOverflow`. No manual FX override (PO_DECISIONS T-112).
