## Description

## Technical details

## Design note (builder, C4)
- Extension has no UI (no copy, so no l10n). Rejections are a one-byte encrypted reason in `spool/files/rejection.bin`, shown once by the app (`takePendingRejection`).
- Spool key via `SpoolKeychain` shared group; the extension never creates plaintext files of its own (the system's temp copy is read inside the handler).
- Negative proofs: unsupported type leaves nothing (only the reason slot); a write failure at each of 4 file steps leaves no partial file.

## Open questions / contract proposal
- **Path for OCR:** Dart needs the encrypted file path of an iOS image share. Proposal: add `String? ocrPath` to `ShareDescriptor` (iOS image only; null on Android). Not done here (no silent widening). Until then the app can use `readShare` bytes.
- **Back Tap guide** (setup doc/screen) is not built here; needs copy-deck keys.
- Missing l10n keys: none (extension has no UI).

## Manual device steps (open)
1. Install a dev build; share a screenshot from Photos, a PDF from Files and text from Messages to Zaghlol; open the app: each appears (ShareIntake resume), nothing was shown by the extension.
2. Share a .zip: nothing appears; the app reports the refusal once.
3. Inspect the App Group container (Xcode device files): only `spool/files/*.bin|.meta`, no plaintext, nothing at the root.
