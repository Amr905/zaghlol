## Description
Discovery card when ≥ 3 distinct eligible uncategorised merchants exist (shown ≤ 3 times, ≥ 30 days apart, "never" respected). Consent sheet (Allow → `cat.llm_consent`, sender starts; Not now → nothing stored). Settings → Privacy row while the flag is on: switch (off → clear consent, empty the queue), counter line from `cat.llm_quota` (unknown before first contact, hidden while paused), "What's sent?" read-only sheet, server-knows item. Queue header counter while on; a passive suggestion row while off. Flag off → no card, no row, existing chips and controls stay.

## Acceptance criteria
1. Card frequency tests: 2 merchants → no card; 3rd → card once; dismissed → not again for 30 days; never after 3 showings or "never".
2. Consent: Not now → nothing sent (sender fake count 0); switch off → queue emptied.
3. Goldens of card, sheet, settings row, queue header: ar/en, light/dark, 130 %.
4. Flag off hides card, row and counter; chips from T-311 remain.
