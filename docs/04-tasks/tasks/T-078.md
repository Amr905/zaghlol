## Design note (T-078 builder, Sonnet)
Implemented in `app/lib/features/capture/application/ignore_rules.dart` (`IgnoreRulesService`). Rule = (institution, optional last-4, channel); a before-seen card is a rule with no account. Add: validate (Arabic digits normalized), commit rule, `onRuleChanged` (Guard config flush), then the existing-data action. Keep is the default. Delete is the typed `DeleteExisting(confirmedIds)` taken from `previewMatches`; only ids that still match the rule and are live are deleted (soft delete through `BulkEditUseCase`, Undo batch per chunk of 1000), then `TransferPairing.onRemoved` for each paired leg (FU-127). Un-ignore removes the rule and flushes config only; transactions, pairs and offset links stay (EC-63); it returns a `RescanOffer` for SMS rules when re-scan is available (Android). AC2 (no trace) is held by the ingest drop path, tested in `ingest_raw_messages_test.dart` ("an ignore rule added after spooling").
