## Scope
1. New route `/currency/:iso` in `app/lib/core/routing/app_router.dart` and a screen `app/lib/features/home/presentation/currency_view_screen.dart`, title «الشهر ده بالـ{currency}». An unknown or invalid ISO code shows a friendly empty state, never a crash.
2. Same layout as the Home hero, **in that currency only**: money in (income + exchanged in), spent, exchanged out (muted line), left; its own budget bar if a budget in that currency exists. It never shows another currency's numbers.
3. Its own feed: this month's transactions in that currency (reuse the transactions list with a currency filter; add the filter to `txn_list_providers.dart` if missing), and a "see all" that opens the transactions list filtered to that currency.
4. «تعمل ميزانية بالـ{currency}؟» offer when the currency had real activity this month and has no budget: offered once per currency per month, dismissible; Yes opens the existing budget editor preset to that currency. Never creates a budget by itself.
5. Strings ar (Egyptian) + en (plan §6 `currencyView.title`, `budget.offer.foreign`), RTL, 1.3×, light/dark, screen-reader labels.

## Acceptance criteria
- PO story: USD view shows money in 1,000, exchanged out 600, left 400, feed with the salary and the exchange; no EGP figure anywhere on the screen (widget test).
- Budget offer: shown once, dismiss remembered, Yes opens the editor with USD; never shown when a USD budget exists.
- Transactions list currency filter test.
- Goldens ar/en light/dark (app-regen workflow).
