## Scope
T-213 fixed the scan-results sheet flash but did not check the native launch screen. Make the Android launch screen (`android/app/src/main/res/values*/styles.xml`, `drawable*/launch_background.xml`, `values-night*`, Android 12+ `windowSplashScreen*`) and the iOS LaunchScreen use the app's background for the current system theme (Mint Fresh bg `#F3FBF7` light, True Black `#000000` dark, D-79) with the app icon centred, so there is no white or mismatched frame between the launch screen and the first Flutter frame. If the app's theme setting differs from the system theme (user picked dark on a light phone), keep the Flutter first frame on the app background as early as possible and say what remains.

## Acceptance criteria
1. Light and dark launch resources match the theme tokens; Android 12+ splash API used where present.
2. A unit/resource test or script check that the colours match `docs/02-design/05-theme-2026.md` (no hard-coded drift).
3. iOS LaunchScreen storyboard updated (CI builds iOS; opt in with `ci/T-220` if you change Swift/Xcode files).
4. `dart analyze`, `dart format`, Android unit/lint checks you can run here; note what needs a phone.
