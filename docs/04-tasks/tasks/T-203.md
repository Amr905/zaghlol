## Description
**Rework.** T-024 shipped per-platform bars (iOS 26 floating glass capsule + detached Add; Android M3 NavigationBar + FAB). Replace both with the one shared bar below (D-77, D-78). Routing, tab state and deep links already work: keep them.

Navigation skeleton per 03-navigation.md.

## Technical details
go_router stateful shell with 4 tabs (الرئيسية/الحسبة/فلوسي/زغلول); modal Add sheet route (S-30); deep links zaghlol://add, review, widget tap.

**Bottom bar = option A (D-78, selected 2026-11-19).** One widget, identical on Android and iOS (D-77); build 04-design-system C-02 exactly:
- Solid bar docked to the bottom: `surface` fill, 1 dp `outline` top edge, soft upward shadow in light only (none in dark). Height 64 dp + bottom safe-area / gesture-nav inset.
- Five equal slots, RTL order الرئيسية · الحسبة · **Add** · فلوسي · زغلول (mirrored in LTR).
- Tabs: 24 dp icon inside a 56×30 dp indicator pill + 12 sp label, labels always shown. Active = `primaryContainer` pill, filled icon, bold label in `primary`; inactive = outline icon, `textMuted` label.
- Centre Add: 62 dp circle, apricot `accent` gradient (#FFCB8E → #FFA94D) with on-accent «+», raised 34 dp above the bar, 5 dp ring in the bar colour, label «سجّل» / Add under it. Tap opens S-30 from any tab.
- Dark (True Black, D-79): bar #141414, top edge #242424, active pill #2A2A2A with white icon and label, inactive #A8A8A8; Add unchanged.
- Scrollable content ends at the bar's top edge (nothing scrolls under the bar, no fade); lists get 40 dp end padding so the last row can scroll clear of the raised Add.
- Bar hides while the keyboard is open. At 130 % text scale labels may wrap to 2 lines and the bar grows. Badge (max 9+) only on S-51 when its flag is on.

Visual reference: mockups 03-home (light), 21-home-dark (dark), 20-android-home, 22-home-english (LTR); options canvas artboard Bar A (https://claude.ai/artifact/B1cDPrieA5aBMth4GBT78U; mockups in `docs/02-design/mockups/` (round 5)).
