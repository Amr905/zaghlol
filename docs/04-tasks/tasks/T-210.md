## Design
`docs/02-design/mockups/charts-v2/Charts2-3-categories.dc.html`; copy and layout in `gen_charts_v2.py` (`categories_tab`, `catsTab*`, `catTrend*`, `tapCat*`). Decision row CHARTS-V2 binds this task.

## Description
The Categories tab: title with total and category count, a sort control (largest first / biggest change), a stacked share strip of all categories, then every category as a ranked bar row (reuse T-209's category row widget, with the previous-period tick and change), then a 6-month trend card for the selected category (tap a row to select; the first row is selected by default) with an "Open transactions" action that opens the existing drill-down.

## Acceptance criteria
1. All categories with spending in the period are listed, uncategorized included (its own label); per-currency rules as in T-209 (primary currency; other currencies listed separately, never summed).
2. Sort by amount or by change; ties broken by name, stable.
3. Share strip segments sum to 100 % with integer basis points (largest-remainder rounding), 2 px gaps, at most 6 named segments plus "Other".
4. Selected-category trend uses 6 periods ending with the current one, the current one marked as in progress while open.
5. Gate follows the category chart's gate in `chart_gate.dart`; hide amounts masks every amount; RTL/LTR, light/dark, digits setting; strings in ARB + copy deck.
6. Unit tests for sorting and share rounding; widget tests; goldens ar/en × light/dark via `app-regen`.
7. `dart analyze` clean, `dart format`, insights tests green.
