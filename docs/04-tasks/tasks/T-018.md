## Input from T-017 (2026-11-11)
- **`categories` already exists (schema v2).** T-017 created it, because `transactions.category_id REFERENCES categories(id)` needs its parent and adding the FK later would mean rebuilding `transactions` with its FTS triggers. It is the §2.4 DDL plus `id NOT NULL` and `CHECK (x IN (0,1))` on `is_custom`/`is_archived` (`app/lib/core/db/schema/financial.drift`). T-018 owns its DAO, seeds and every other §2.4–2.5 table; any change to `categories` is a v3 step.
- **How to add tables.** Write the SQL in a `.drift` file in `app/lib/core/db/schema/` and include it from `AppSchema`; bump `appSchemaVersion` and `schemaVersion`; run `app/tool/generate_drift.sh` (now fails on any drift_dev warning). Write the step as a frozen statement list like `app/lib/core/db/migrations/v2_financial_a.dart` with a test against the new dump: drift_dev 2.35.3's generated `SchemaN` can miss entities (it dropped both T-017 FTS-related tables and the view). `replace` must be written `"replace"(…)` and `printf` as `format` in `.drift` files. Money columns: copy the T-017 CHECK pattern (design note §4). `FakeNextDatabase` follows `appSchemaVersion` automatically.
