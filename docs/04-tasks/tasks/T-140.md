## Description
Provider-neutral cloud setup, including the KMS keys and store-console settings the Gold design relies on.

## Technical details
- Modules: container service ×2, worker, managed PG 17 HA + PITR 14 d, object storage + CDN, secrets, WAF, Pub/Sub topic + push, DNS/TLS; OIDC-federated deploys; migration job; rollback.
- **KMS keys** with least-privilege policies (API identity may sign / MAC, never export): entitlement and sync signing keys (next/active/retired), **`K_seat`** (seat-key HMAC, D-62), **`K_audit`** (e-mail pseudonym, D-47), the `install_hash` pepper, the idempotency-body envelope key.
- Edge: WAF / LB / CDN log no query strings; body inspection samples disabled or redacted for `/v1/apple/*` and `/v1/notifications/*`.
- **Launch checklist** (`docs/ops/launch-checklist.md`): Play Console optional integrity verdicts (`deviceAttributes`, `recentDeviceActivity`, `appAccessRiskVerdict`, `environmentDetails`) **off** (R2-7, D-45); Play Integrity daily quota checked and the 50 % alert wired, with a quota-increase request as the runbook action; App Attest environment per stage (`aaguid` production in prod, development in staging); Play Developer API service account has the `orders` permission if T-130 adopted `orders.get`.
