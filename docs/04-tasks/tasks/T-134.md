## Description
Apple lifecycle events update Gold.

## Technical details
- Read only `signedPayload`; verify the x5c chain to Apple Root CA G3, the signature, `bundleId` and `environment`, then the nested `signedTransactionInfo` / `signedRenewalInfo` JWS; nothing is written before all pass (`401` otherwise).
- Open envelope: unknown fields ignored, never stored or logged; DTOs list exactly the fields read (no `[JsonExtensionData]` / `JsonElement` / dictionary rest); `x-third-party-body: true`.
- Dedupe `notificationUUID`; return 200 after storing the extracted columns plus `payload_digest`; handle `SUBSCRIBED`, `DID_RENEW`, `DID_FAIL_TO_RENEW` (grace), `EXPIRED`, `GRACE_PERIOD_EXPIRED`, `REFUND`, `REVOKE`, `DID_CHANGE_RENEWAL_STATUS`; `Get Notification History` reconciliation. Production and sandbox URLs.
- State changes write `purchase_events` (`assn:<type>`); a notification never moves a seat.
