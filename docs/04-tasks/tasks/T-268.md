## Scope
1. Compare the animated mascot in the app (interim brand art from T-099, `docs/02-design/mascot-rive-handoff.md`, assets under `app/assets/`) with the approved art in `docs/02-design/brand/`. Find why the left hand is cut: asset canvas too tight, clip (`ClipRect`/`ClipOval`), `BoxFit`, animation transform moving the hand outside the box, or a mirrored RTL layout.
2. Fix in code if it is layout/clip/transform (padding the paint bounds, `Clip.none`, correct fit). If the asset itself is cut, do NOT redraw the mascot: say so in the task file with the file and pixel bounds, and use the approved static art where the cut would show.
3. Golden tests of every mascot state at 1× and 1.3× text scale, ar/en, via app-regen only; view the regenerated PNGs to confirm the hand is whole.

## Acceptance criteria
Root cause in the task file; goldens show the whole mascot; no clipping in RTL.

## Root cause (builder)
Viewed `app/assets/mascot/zaghlol_still.png` (494x512), `docs/02-design/brand/zaghlol-mascot-rig-preview.png`, `zaghlol-mascot-coin.png`, `docs/02-design/mascot-riv/lab-vs-riv/idle.png` and `app/test/goldens/mascot_moods_en_light.png`. The left thumbs-up hand is whole in every one of them: the shipped still is NOT cut. But the still has no transparent margin at all (alpha bbox = full 0,0,494,512; the left hand's outline starts at pixel column 1-2, alpha 5/57/160 at x=1/2/3, fully opaque by x=5), unlike the brand render, which has a small margin. The art is therefore flush with the box, so anything that clips the box edge nibbles the hand: `RiveWidget` paints clipped to its bounds, ancestor `Clip` widgets (cards, bubbles), and the interim rotate/scale/shake poses (scale up to 1.08, dx 3%) push the hand past the box. No `ClipRect`/`ClipOval` and no RTL mirroring in the mascot code (InterimMascot already uses Clip.none). The Rive artboard could not be rendered in tests (native runtime), so its own margin is unverified; the inset below covers it too.

## Fix
`ZaghlolAvatar` paints the art (still, interim, Rive, artboard override) inside a symmetric 6% inset on each side (`paintInsetFraction`), centred in the same `size` box (layout size unchanged). Test: `zaghlol_avatar_test.dart` "T-268 art stays inside the box" (LTR and RTL). Goldens: regenerate via app-regen.

## Builder assumptions
Goldens existing for the avatar and the moods screen (ar/en, light/dark) are regenerated; no new 1.3x mood golden was added (the avatar is fixed-size art, text scale does not affect it).
