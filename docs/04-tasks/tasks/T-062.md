## Design note (builder, Sonnet; C4 non-crypto-primitive, 2026-11-14)
- **Mirror, not new design.** Entry format (`nonce12 || AES-GCM || tag16`, AAD `zaghlol.spool.v1|entry|<ulid>`), the versioned binary record, ULID names, caps (500 / 4 MiB, generic budget 250 / 2 MiB / 10 per min, sms share 80 %), held area, tmp+fsync+rename writes, drain claim, capture status record and coalescing are the Android ones, so `IngestionRunner`/`PigeonSpoolPort` logic is shared. Only `IosPigeonSpoolPort` (same `SpoolPort`) is new on the Dart side; `platformSpoolPort()` picks it on iOS.
- **Code placement.** `app/ios/Shared/` holds everything an extension must compile (`SpoolStore`, `SpoolRecord`, `SpoolCipher`, `SpoolKeychain`, `CaptureStatusStore`, `SpoolLocation`, `SharedGroups`, `SpoolUlid`); `app/ios/Runner/Platform/Capture/` holds the Runner-only parts (`IosCaptureHost`, `SpoolClaim`, `HeadlessIngestion`, `IngestBackgroundRefresh`). T-061/T-063 add the `Shared` files to their targets.
- **Key.** Keychain generic password `app.zaghlol.spool` / `spool_key_v1`, 32 random bytes, `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`, not synchronizable, access group `<AppIdentifierPrefix><bundle id>.shared` (listed in `keychain-access-groups` after the app's own group, so the K_db item's explicit group is unchanged). Reads classify like `DbKeyKeychain` (retry 100/300/900 ms; only an agreed `notFound`/wrong-length item leads to a create/replace; `errSecInteractionNotAllowed` and every other status is transient and creates or deletes nothing); a concurrent create (app and extension) ends in `errSecDuplicateItem` and the loser reads the winner's key. The app pre-creates the key at launch off the main thread.
- **Multi-process.** The app and the extensions write the same directory. An entry is complete or absent by `.tmp` + `F_FULLFSYNC` + atomic `rename`; caps may overshoot by the writes in flight; `sweepTmp` only removes `.tmp` older than 10 min (a younger one may be another process's write); the status file is read-modify-written under `flock`. File protection class `completeUntilFirstUserAuthentication`, the same availability as the key.
- **Backups.** `ensureExcluded` runs on the spool and status directories in the writer before the first write (T-165 F5), and at launch via `ZaghlolDirectories.applyAll`. `ZaghlolDirectories.appGroupIdentifier` now reads `ZaghlolAppGroup` from Info.plist (`group.$(PRODUCT_BUNDLE_IDENTIFIER)`, one value per flavor). Nothing is written at the container root.
- **Headless path (ADR-006 addendum).** The caller (T-061 intent) writes the spool entry first; `HeadlessIngestion.attempt(timeoutS: 8)` then tries one drain cycle in a `FlutterEngine` at `ingestionMain`: handlers installed only after `engine.run()`, Dart retries `ready` (25 ms, 400 times) until native answers, hard timeout for the whole run; on timeout or BGTask expiry native sends `close` (Dart stops after the current batch and closes the DB) and waits at most 3 s before `destroyContext()`. Any failure leaves the entry in the spool (foreground drain / BGAppRefreshTask). The `app.zaghlol.ingest` BGAppRefreshTask handler is registered in `didFinishLaunching`, reschedules first, and runs the same headless cycle (20 s).
- **Contract additions (flag to the Lead).** `IosCaptureHostApi` gains `holdSpool`, `getSpoolStatus`, `clearSpoolAlerts` (platform-channels.md section 3 listed only drain/ack/register); `ingestion_api.dart` gets a Swift output. `writeGuardConfig` and the Shortcut-setup methods stay with T-061.
