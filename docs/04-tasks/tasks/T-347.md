## Description
Views for each `LlmAnswer` kind: data answers with per-currency blocks and "Open in Transactions"; COMPARE % line; AVERAGE full-units caption; what-if with basis/capped/not-enough captions (`proud` once); suggestions rows (tile · sentence · save label, cash tip, none); invest lead + instrument rows (gold, ≈ USD, certificate, stale badge, ≈ caption, `noPrice`) and the always-visible disclaimer block; bands (nothing saved, small, stocks, gold); refusal copy with chips (specificPick chip hidden when `ask_llm_invest` is off; support line for self-harm cues); fallback chips. Footer: `sent_badge` + "What I sent". Mini chart (C-13 compact) with a text alternative where the UX table has one. Local chips that run a plan (`invest_suggestChip`, `invest_chip`) execute on the phone with no request.

## Acceptance criteria
1. Goldens for each UX §5 example and each D-93 band, ar/en, light/dark; invest rows stack at 130 %.
2. Disclaimer block always visible for PL-INVEST with instruments, never collapsed; absent for `small`/`nothingSaved`.
3. Hide amounts: amounts masked and announced "amount hidden"; grams hidden; percentages kept.
4. Tapping `invest_chip` / `invest_suggestChip` makes no network request (fake client count 0) and uses no quota.
5. No amount rendered in red; card digits Western.
