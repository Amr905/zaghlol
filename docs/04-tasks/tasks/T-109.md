## Description
One phrase becomes several categorized items.

## Technical details
Number words (ميت وخمسين, نص, ربع, ألفين…), currency words, item splitting, verb stripping, categorization, missing-amount flag (EC-30), mixed language (EC-31).

## Design note
(Short note written by the implementer; no architect note existed.)

- **Split:** `parseVoicePhrase(text, defaultCurrency:)` is pure and sync (`packages/zaghlol_parsing/lib/voice/`); `categorizeVoiceItems(items, ports)` is async and reuses the T-075 `Categorizer` (user rule, catalog merchant, keywords, needs classification). Result is `VoiceParsed(items)` or `VoiceUnrecognized(reason)`; never throws. Input cap 1000 chars, 300 tokens.
- **Normalize:** T-013 `normalizeText` (Arabic-Indic digits, `٫`, `٬`) then per-token `foldKey` for lookups; display text keeps the original spelling. Word tables are data in `voice_lexicon.dart`.
- **Amounts:** exact integer rationals, converted once to minor units with the currency exponent (half up; only "تلت" is inexact). No `double`. Grammar: units, teens, tens, hundreds (ميت/ميه/تلتميه...), thousands (ألف/ألفين/تلات تلاف/k), million, "و" joins only where the magnitudes descend (ميت وخمسين = 150; خمسة وعشرين = 25), a fraction after a round number is of its unit (ألف ونص = 1500, ميت ونص = 150) and of one pound after a small number or currency (عشرة ونص = 10.5, جنيه ونص = 1.5); "نص كيلو" is a measure, not money; piasters (قرش).
- **Items:** amount spans split the phrase. If real words precede the first amount the phrase is text-first ("قهوة 50 وتاكسي 30", "بـ"), otherwise amount-first ("دفعت 150 جنيه خضار وفاكهة و 45 قهوة"). A "و" inside the words of one item does not split. Text with no amount at all splits at conjunctions.
- **EC-30:** items carry `issues` (`missingAmount`, `missingItemText`, `invalidAmount`, `ambiguousCurrency`). **EC-31:** Latin words are ordinary item text and reach the catalog merchant matcher.
- **Quantities:** a bare number 1..10 with no currency, not after "و", in a phrase that also has a priced amount (currency word or `ب`) is a quantity, not an amount.
- **Currency:** spoken word or symbol wins; otherwise the default. `دينار` is ambiguous (flagged, default used). An unspoken currency in a phrase that speaks a different one is flagged. Nothing is converted.
- **Confidence (thousandths):** digits 1000, number words 950, fraction word 900; minus 300 for no item text, 200 for ambiguous currency; scaled by how the category was found (rule/exact 1000, prefix/token 950, keyword 900, fuzzy 850, none 600).
- **Fixtures:** `packages/zaghlol_parsing/test/fixtures/voice/phrases.json` (synthetic; expected values written independently of the parser) and `keywords.json` (synthetic keyword set standing in for the catalog).
