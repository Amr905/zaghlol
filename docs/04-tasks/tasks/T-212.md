## Design note (builder, 2026-11-23)

**Generator.** Our own deterministic Python generator in `tools/mascot_riv/` (stdlib only, no pip deps) writes the `.riv` v7 binary directly. Type keys, property keys and field types come from the official generated headers of `rive-app/rive-runtime` at commit `eaa5e03cfa81ab3cdfa002e8b4ed40d957194fa4` (the public repo no longer ships `dev/defs`; `include/rive/generated/**/*_base.hpp` carries the same typeKey/propertyKey/field-type data). `extract_defs.py` turns them into the committed, trimmed `rive_defs.json` (only the types we emit plus ancestors). No rive-mcp-server code is used or vendored.

**File layout** (as the runtime importer expects, `src/file.cpp`, `runtime_object_reader.cpp`): header `RIVE` + major 7 + minor 0 + fileId 0 + property ToC; `Backboard`; `Artboard` `Zaghlol` (1000x1000); components in hierarchy order with `parentId` = artboard-local index (artboard = 0; interpolators also claim a slot); then `LinearAnimation` > `KeyedObject` > `KeyedProperty` > `KeyFrameDouble`; then `StateMachine` with inputs, layers, states, transitions, conditions. Draw order = file order. Curves: the rig's quadratic segments become `CubicDetachedVertex` (exact 2/3 degree elevation).

**Rig mapping.** Each of the ten SVG groups becomes a `Node` pivoted where it should rotate (tail root, shoulder, brow/eye centres, jaw hinge); a `character` node (pivot at the feet) carries body motion (breathing, hop, lean, squash) and a `face` node carries gaze. Every animation keys the full set of animated properties (rest values where a mood does not move them), so switching moods never leaves a part displaced.

**State machine.** Layer 1 (moods): Entry -> Idle; Idle/Rest_k/Mood_k -> Mood_j when `state == j`; one-offs return to a per-mood rest state (idle animation) by exit time so the still-set `state` does not re-trigger; `state < 0` returns to Idle (file preview default is -1). Layer 2 (talk): TalkOff <-> TalkOn on `talk`, jaw/beak/cere only. `reduceMotion` bool: when true the idle layer holds the rest pose (no breathing/blink) and no mood is entered.

**Validation.** (1) Official `@rive-app/canvas-advanced` WASM runtime in headless Chrome (puppeteer-core, `tools/mascot_riv/verify/`): load, list artboard/state machine/inputs by name and type, then for every `state` 0-14 and `talk` true/false advance time and read the animated node transforms (`artboard.node(name)`) to prove the intended animation is playing, plus a replay check. The same page renders the contact-sheet PNGs. (2) `flutter test` loads the asset through the app's `rive` runtime if the native lib is available in the test host; otherwise it only asserts the asset is declared. (3) Generator run twice, bytes compared.
