## Why
T-212 generated `zaghlol.riv` with simplified transforms only. On the phone the PO mostly sees the idle blink. The **approved** motion is the Motion Lab: `docs/02-design/motion/zaghlol-motion.html` (34 `@keyframes`: blink, breathe, wag, burst, dot, drip, droop, drop, fall, flapL, flip, flyin, grow, hop, lean, listen, look, nod, point, ponder, puff, pump, ring, scan, scratch, shake, shuffle, spin, talk, tapw, tilt, tilt2, zz…) on the rig parts `zt-base, zt-beak, zt-jaw, zt-browL/R, zt-eyeL/R, zt-cere, zt-tail, zt-wing`, with props (coins, flipping coin, dots, envelopes flying in with a live count, coins dropping, confetti, coin rain, cloud, Zzz). Table and rules: `docs/02-design/08-mascot-motion-and-bank-logos.md` §1.

## Scope
1. **Port the Motion Lab into the generator** (`tools/mascot_riv/`): for each of the 15 moments plus idle and talk, reproduce the Lab's per-part keyframes (same parts, transform origins, values, easings, durations, delays and loop behaviour) and its props (as vector shapes in the artboard, hidden unless their mood runs). Idle = breathe + blink every ~4 s + tail wag. Read the Lab's CSS/JS literally; don't re-imagine. Text in the Lab (e.g. the live count) is not part of the file; the app shows its own lines.
2. **Behaviour per the doc:** one-offs last ≤ 3 s and return to idle; loops (listening, thinking, scanning/reading, counting) loop while the input holds; sleep = two breaths then still (eyes closed); pull follows; tap = hop + spin.
3. **Verification:** extend `tools/mascot_riv/verify/` to (a) check every mood's keyed parts and props against an expectations file derived from the Lab, and (b) render side-by-side contact sheets: the Lab (headless Chrome screenshot of each moment at the same times) vs the `.riv` (official WASM runtime) at 3 time points per mood; commit them in `docs/02-design/mascot-riv/lab-vs-riv/`. Look at them yourself and fix visible differences.
4. **Device check:** extend T-231's `rive_mascot_device_test.dart` so every `state` 0–14 and `talk` are set on the emulator and the state machine reports the matching animation/state (via the runtime's state-change reporting); runs in `device-flows`.
5. **Mood preview screen (dev flavor only):** under the existing developer/diagnostics menu, a "Zaghlol's moods" screen with one button per moment (and a talk switch) that plays it on a large `ZaghlolAvatar`, so the PO can see every mood on the phone. Not in prod builds; strings via ARB.
6. Size ≤ 500 KB; deterministic generator.

## Design note (builder, 2026-11-23)

**Approach: parse the Lab, do not re-key it by hand.** `tools/mascot_riv/labcss.py` reads `docs/02-design/motion/zaghlol-motion.html` (the `<style>` block: `@keyframes`, `.zg .part` base rules, `.st-<mood> .part` rules, cascade by specificity then order) and the JS prop table (`props()`), and `motion.py` compiles the result into Rive animations. Values, durations, easings (`ease`, `ease-in-out`, `ease-in`, `ease-out`, `linear`, the three custom cubic-beziers), delays, iteration counts and `forwards`/`both` fill come from the file; a CSS transform list is decomposed to x/y/rotation/scaleX/scaleY, which Rive keys with cubic-ease keyframes (cubic bezier = Rive CubicEase).

**Scene.** One `stage` node scales the Lab's user units (SVG viewBox units, so `translateY(-140px)` is 140 units) into the 1000 square artboard (scale 0.76, bird centred, headroom for props). Under it the Lab hierarchy exactly: `bird` (460,940) > `breath` (460,920) > `tail` (780,600), base, `wingL` (200,520) > `pointer`, `head` (400,300) > `brows` (430,145), `eyeHappyL/R`, `eyeOpenL/R` > `eye` (fill-box centre) > `pupils`, `eyeClosed`, `jaw` (440,272), `mouthClosed`, beak, cere, `glasses`, `hat`, `mag`, `sweat`. Pivots come from the CSS `transform-origin`. The HTML props live under an `fx` node scaled so the Lab's stage pixels (380x400, bird at 76% height) map 1:1: `coin`, `dots`, `env`, `conf`, `ring`, `cloud`, `z`, `bars` as vector shapes.

**State machine layers** (a layer per independent clock, as in the Lab): `breath` (breathe 3 s), `tail` (wag 2.6 s), `blink` (blink 4.2 s) ambient loops; `moods` (bird/head/wing/brows/pupils/eye/jaw transforms and the expression groups, shown or hidden by `opacity`, as CSS `display`); `fx` (prop clocks that differ from the body: scan envelopes 1.6 s vs head 2 s, rings 1.8 s, Zzz 2.4 s, confetti 1.4 s); `talk` (jaw `talk` .34 s); `reduceMotion` (rest pose). All driven by the same `state` number (-1 = idle).

**Differences from the Lab, on purpose:** (1) idle blink also closes the happy eyes (doc section 1: "blinks every ~4 s"; the Lab only blinks the open eyes); (2) loops do not reproduce the Lab's start-up delays (five count coins share one phase, so one coin is drawn); (3) Math.random in the Lab (confetti, rain) is replaced by a fixed seed, the same seed in the contact-sheet capture; (4) sleep stops after two breaths and the Zzz stop with it; (5) props use the light-theme colours; (6) bird about 11% smaller in its box to leave room for props. Verification: `verify/expectations.json` (from the Lab) vs the runtime, and `docs/02-design/mascot-riv/lab-vs-riv/` contact sheets.
