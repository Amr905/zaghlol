## Implementation notes (2026-11-15)

**Provider conventions (this task).** Notification-capture institutions (no SMS sender, `packages` only): body = title + content, which the engine folds to one line (line breaks become spaces), so patterns never rely on `\n`. All templates are `"source": "synthetic-unverified"` (no real samples; wording modelled on each provider's public help pages and common formats). Replace with real wording when samples arrive: `grep -l synthetic-unverified app/assets/registry/institutions/*`. Limit wording maps to `available`, never `balance`. FX conventions: `fx_conversion` (direction `neutral`): `amount` = the debited (from) leg, `originalAmount`/`originalCurrency` = the received (to) leg; T-089 turns the two into the two legs. `card_purchase_fx` (Wise): `amount` = charged account-currency figure, `originalAmount` = foreign. `pending_auth`/`settled` (Revolut) carry the merchant so the EC-54 merge can match. `fx_conversion` templates use baseConfidence 0.97 (no last4 or merchant, so the `sparseFields` factor would otherwise push them under the auto-accept threshold). No ARB keys needed. The Guard base and `spike_guard_base.json` were regenerated; `bundled_registry_e2e_test` institution count is now 60.

**Templates (all `synthetic-unverified`, SMS):**
- `hdfc`: card_purchase.en, transfer_out.en, transfer_in.en, atm_withdrawal.en
- `paytm`: card_purchase.en, wallet_topup.en, transfer_in.en, transfer_out.en
- `alrajhi`: card_purchase.en, card_purchase.ar, transfer_in.en, transfer_in.ar, atm_withdrawal.en, atm_withdrawal.ar, declined.en
- `enbd`: card_purchase.en, card_purchase.ar, atm_withdrawal.en, salary.en, declined.en
- `liv`: card_purchase.en, card_purchase.ar, transfer_in.en, refund.en
- `warba`: card_purchase.en, card_purchase.ar, transfer_in.en, declined.en

New institutions and senders: `hdfc` (HDFCBK, INR), `paytm` (PAYTMB, INR), `alrajhi` (AlRajhiBank, SAR), `enbd` (ENBD, AED; separate from the existing Egypt-branch `emirates_nbd`), `liv` (Liv, AED), `warba` (Warba, KWD, 3 decimals). Fixtures: 113 (4 per template; Arabic digits on the AR ones). Al Rajhi multi-line SMS are matched on the collapsed single-line text. Guard base regenerated.

**AC map.** `₹1,23,456.78` / `Rs.1,23,456.78` (EC-51): `hdfc/card_purchase_en_indian_grouping.json`, pipeline test 3-4. `KWD 12.345` not truncated (EC-36): `warba/card_purchase_en_three_decimals.json`, pipeline test 5.
