## As built (implementer, 2026-11-11)
- Port `features/transactions/domain/transaction_repository.dart` (pure Dart entity, filter, edit types in `transaction.dart`); Drift implementation `data/drift_transaction_repository.dart`; Riverpod wiring `data/transactions_providers.dart` (`transactionRepositoryProvider`, injectable clock and id generator).
- DAO additions (`core/db/daos/transactions_dao.dart`): `TxnQuery`, `list`, `countMatching`, `restore`, `purgeDeletedAtOrBefore`, `inTransaction`; `softDelete` now changes live rows only (keeps the first `deleted_at`, the purge clock).
- **Short-query routing:** 1-2 character text uses the word-prefix table; a 1-2 digit text (Latin or Arabic-Indic) also matches amounts whose whole-unit part equals the number (`amount_text LIKE 'N.%' / 'N %'`). Three or more characters use the trigram table (names, notes, amount text). Filters combine with AND.
- **Edit/add:** any add/edit sets `is_user_verified = 1`; a category change sets `category_source` to `user` (or `none` when cleared); retyping the merchant clears `merchant_norm`. Source stays as captured.
- **T-017 m-4 decision:** a soft delete keeps offset links (Undo restores them untouched; the schema triggers still count them until purge). Net-spend reads use `OffsetLinksDao.activeLinkedToExpense` / `activeLinkedFromSource`, which ignore links whose expense or source is soft-deleted. T-051 and T-089 must use these, not `linkedToExpense`.
- **T-017 m-2:** the repository exposes no write to `split_participants`, so `expense_txn_id` immutability is not reachable here; the split-participants writer (T-089) must keep it immutable (or add the trigger).
- **Purge:** `purgeExpired()` hard-deletes rows with `deleted_at` 30+ days old (cascades to links/pairs; FTS by triggers). Scheduling it (app start / daily job) is not part of this task. Residual: a device clock set far ahead purges early; a clock set back never purges early.
- Bulk delete/restore run in one DB transaction, all or none, up to 1000 ids; filter sets are capped at 1000.
- Evidence: `test/features/transactions/data/drift_transaction_repository_test.dart` (33 tests), benchmark `transactions_search_benchmark_test.dart` (tag `benchmark`; host p95 about 57 ms at 50k rows, gate 200 ms).
