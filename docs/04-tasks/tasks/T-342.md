## Description
One function per plan variant producing typed answer models (`LlmAnswer` sealed: data, compare, breakdown, topN, average, income, saved, bills, budgetLeft, safeSpend, balance, whatIf, suggest, invest, notFound(chips), fallback, refuse). Resolve placeholders through the in-memory map, mentions through the existing matcher (no match → `notFound` with chips, never a guess). Feeds T-326/T-327 calculators with aggregated per-currency inputs and prices (`XAU21_G`/`XAU24_G`, FX). Results per currency, primary first; ≈ USD lines only when labelled.

## Acceptance criteria
1. Fixture DB (Ahmed, SRS §10): PL-COMPARE dining → +EGP 200.00 (+6 %) with the USD line separate; PL-AVERAGE per day last cycle → EGP 661.29; PL-SAVED → EGP 4 500.00; PL-SPEND with `⟦CARD_1⟧` → card 4321 only.
2. A `mention` not in the user's data → `notFound` with chips; a placeholder missing from the map → `fallback`.
3. EC-24: PL-SAFE-SPEND with no budget → the hint variant, no figure.
4. No cross-currency sum in any result (test with EGP + USD data for every data plan).
5. No `double` in the feature (static test); half-even once per figure.

## Design note (builder, T-342)
- `PlanExecutor.execute(Plan, MaskMap)` in `app/lib/features/ask/application/plan_executor.dart`; typed `LlmAnswer` sealed family in `app/lib/features/ask/domain/llm_answer_models.dart` (all `Llm*` names, no clash). Never throws: any failure is `LlmFallbackAnswer(failed)`. Read-only: no network, no writes, no logging.
- Inputs are injected like `AskEngine` (charts, accounts, cycle budgets, schedule, entities, today) plus gold/FX prices, `now`, primary currency (EGP), invest and suggest thresholds.
- Filters: `slug` -> `sys:<slug>`; `ref` -> mask map (missing -> `fallback(missingPlaceholder)`; bank/card with no accounts -> `notFound`); `mention` -> the existing Ask matcher through `parseAskQuestion('صرفت كام على <mention>')`, no match -> `notFound` with chips of the user's own names. Merchant mask ids are `merchant_norm` (as `loadAskEntities` does).
- `ChartRepository` additions: `categoryTotals`, `topExpenses`, `cashPool` (S4 inputs), `categoryBudgets`. Income and saved reuse `cashFlow`; spend reuses `scopedSpend` / `merchantSpend`.
- Full periods: the last 3 payday cycles before the current one, dropping any that starts before the first transaction (EC-23). Averages count full units only (nothing after yesterday, nothing before the first transaction, whole Saturday weeks / whole cycles) and say so (`partialExcluded`).
- Per-currency results, primary first, then by code. `index` instrument is dropped (OQ-ASK-02); only `index` asked -> `fallback(unsupported)`.
- Follow-ups: FU-401 (S1 basis kept as the SRS wording, filed OQ-ASK-09; negative or zero what-if base -> `NotEnoughData`; S1/S3 de-dupe by category id, `Suggestion.categoryId`), FU-407 (`InvestThresholds` now throws unless `minEgp` is EGP; the constructor is no longer `const`).
