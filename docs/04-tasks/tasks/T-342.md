## Description
One function per plan variant producing typed answer models (`LlmAnswer` sealed: data, compare, breakdown, topN, average, income, saved, bills, budgetLeft, safeSpend, balance, whatIf, suggest, invest, notFound(chips), fallback, refuse). Resolve placeholders through the in-memory map, mentions through the existing matcher (no match → `notFound` with chips, never a guess). Feeds T-326/T-327 calculators with aggregated per-currency inputs and prices (`XAU21_G`/`XAU24_G`, FX). Results per currency, primary first; ≈ USD lines only when labelled.

## Acceptance criteria
1. Fixture DB (Ahmed, SRS §10): PL-COMPARE dining → +EGP 200.00 (+6 %) with the USD line separate; PL-AVERAGE per day last cycle → EGP 661.29; PL-SAVED → EGP 4 500.00; PL-SPEND with `⟦CARD_1⟧` → card 4321 only.
2. A `mention` not in the user's data → `notFound` with chips; a placeholder missing from the map → `fallback`.
3. EC-24: PL-SAFE-SPEND with no budget → the hint variant, no figure.
4. No cross-currency sum in any result (test with EGP + USD data for every data plan).
5. No `double` in the feature (static test); half-even once per figure.
