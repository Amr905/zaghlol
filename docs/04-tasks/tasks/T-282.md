## Builder assumptions
- The cash-flow "series" is delivered in the data model (`CashFlowPoint.exchangedIn/exchangedOut`, `InOutBar.exchangedInMinor/OutMinor`); the In-and-out bar widget does not draw extra bars yet (UI is not named in scope). A currency reached only by an exchange gets a chip.
- Ask exchange rate = bank rate read from the two legs, quoted as the bigger-major-amount currency per 1 unit of the other (e.g. 1 USD = EGP 49.50). Pairs are listed per currency pair, never summed across pairs. The out leg decides the period.
- Ask savings shows a currency when it has income OR exchanged-in money; the percentage still uses income only.
- New intent `AskIntent.exchange` (parsing package) with cues غيرت / بدلت / تغيير عملة / exchange(d) / converted / swapped; no new chip (chips closed set unchanged).
