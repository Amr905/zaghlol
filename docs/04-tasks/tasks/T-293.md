## Dart API (fixed so the other tasks can call it now)
In `app/lib/core/ui/z_haptics.dart` add:
```dart
enum ZHapticPattern { payday, saved, oops, birdTap }
static Future<void> play(ZHapticPattern pattern) // no-op when disabled
static List<int> timelineMs(ZHapticPattern p)     // hit offsets in ms, for syncing animation beats
```
- **payday** (≈1.6 s, matches the coin rain + bird pop): a rising run of light ticks as coins land (e.g. 0, 140, 260, 360, 450 ms) then one strong "thud" at the bird's pop (~700 ms) and a soft double tap at the end (~1300/1420 ms).
- **saved**: crisp double tap (success), ~0/90 ms.
- **oops**: short low buzz, two pulses.
- **birdTap**: one light tick.
Keep the exact numbers in one table in the task file and `docs/02-design/08-mascot-motion-and-bank-logos.md` (new "Haptics" subsection).

## Native
- **Android** (Kotlin, platform channel `app.zaghlol/haptics`): `VibrationEffect.Composition` primitives (TICK, CLICK, THUD) on API 30+ when `areAllPrimitivesSupported`; else `createWaveform` with amplitudes when `hasAmplitudeControl`; else fall back to Flutter `HapticFeedback` calls on the Dart side. VIBRATE permission if not already declared. Never vibrate when the system "touch feedback"/haptics is off where readable.
- **iOS** (Swift): `CHHapticEngine` pattern (transient events with intensity/sharpness) when `supportsHaptics`; else `UIImpactFeedbackGenerator` steps. Engine started lazily and stopped on background.
- Respect `ZHaptics.enabled` (app setting) and reduce motion (only one light tick then).
