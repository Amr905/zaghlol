## Description
MonsterASP.NET gives one IIS website (Free: 256 MB RAM, `*.runasp.net` subdomain, EU; Premium from $1.95/month: custom domain, automatic HTTPS, planned tasks). There is no separate always-on process for `Zaghlol.Workers`, and IIS app pools idle out.

## Acceptance criteria
1. `Hosting:EmbeddedWorkers = true` registers the worker hosted services (price fetcher, Play/Apple notification processors and sweepers, retention purger, contribution aggregator, Apple revocation retry, heartbeat) inside the API process, with the worker's DB role connection string; off by default, so the two-process layout keeps working. Startup refuses if both the API and a separate worker heartbeat run the same singleton jobs (or document leader-lease reuse if one exists).
2. Framework-dependent `win-x64` publish with `web.config` (ANCM in-process, `stdoutLogEnabled=false`, `environmentVariables` placeholders only), request limits, and `ForwardedHeaders` set for IIS (no proxy trust beyond the host).
3. Catalog snapshots: `Catalog:Snapshots:Directory` under the site's `App_Data` (not web-served directly), served by the existing API route or static files with correct cache headers; `BaseUrl` = the site URL.
4. Deploy workflow (`workflow_dispatch`, environment `backend-production`, required reviewer): build, test, publish, generate `web.config` environment variables from environment secrets, deploy with Web Deploy (msdeploy) using the MonsterASP publish profile secrets; run EF migrations against Aiven as the migrator role before swapping; smoke `GET /v1/health`; keep the previous package for rollback.
5. Keep-alive: a scheduled GitHub Actions workflow pings `/v1/health` every 10 minutes (and Premium's planned task if available) so idle shutdown doesn't stall jobs; jobs must still be safe to resume after a recycle (document).
6. OpenTelemetry exporter off by default on this profile; logs go to the host's log viewer without PII (same filters).
7. Docs: deployment.md "MonsterASP.NET + Aiven" runbook (account, site, publish profile, secrets list, first deploy, custom domain on Premium, rollback).
