## Description
Live SMS capture with personal SMS never stored.

## Technical details
SMS_RECEIVED receiver; assemble multipart PDUs (EC-09); sim slot (EC-11); Guard; spool; goAsync ≤ 5 s; enqueue expedited IngestionWorker; notify engine if attached; nothing logged.

## Design note
Required — solution-architect (Opus) writes it before implementation (C4).

Build the process-wide capture runtime with T-038's `GuardRuntime` and T-039's `SpoolStore`/`CaptureStatusStore`; wire `AndroidCaptureHost(guardWriter = GuardRuntime::writeUser, guardState = …)`. Map Guard kind → `AdmissionClass` (`registry`/`user` → `PRIORITY`, `generic` → `GENERIC`); on `Refused` still enqueue the worker and notify an attached engine; on Guard `rate_limited` call `status.recordRateLimited(sms, wallMs)`; never write anything for a non-financial drop.
