## Build notes (sprint wave 1)
- Widget: `app/lib/features/mascot/presentation/zaghlol_avatar.dart`. `ZaghlolMoment` (15), `ZaghlolAvatar(moment, talk, size, semanticLabel)`, `reduceMotionProvider` (in-app toggle; T-0xx settings writes it), OS reduce motion via `MediaQuery.disableAnimations`.
- Rive seam: `zaghlolArtboardProvider` (null now). T-088 overrides it with a builder; no widget API change. The Rive package is not added.
- Still pose: PNG `assets/mascot/zaghlol_still.png` (512 px copy of brand `zaghlol-mascot-coin.png`); the SVG rig needs flutter_svg, not a dependency. Same still for all moments until the .riv ships.
- Goldens (`test/goldens/zaghlol_avatar_*`) are not committed: generate with the app-regen workflow.
- Needed l10n keys (no ARB edit): none in the widget. Callers pass a localized `semanticLabel`; suggest key `mascot_semantics_label` (ar: "الكابتن زغلول", en: "Captain Zaghlol").
