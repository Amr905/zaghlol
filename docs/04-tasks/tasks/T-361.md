## Description
AI chip (icon + text «اقتراح زغلول» / "Zaghlol's guess") on the transaction row, details, review queue and chart drill-down for `ai` + unconfirmed rows. ✓/✗ on details and the queue, each ≥ 48 dp (44 pt iOS) and ≥ 8 dp apart; ✓ calls `confirm`, ✗ opens the existing category picker then `correct`; cancel changes nothing; a 5 s Undo snackbar calls `undo`. Results announced to screen readers.

## Acceptance criteria
1. Widget tests: chip shown only for `ai` + unconfirmed; ✓ / ✗ / cancel / Undo call the right service methods (fake).
2. Goldens of row, details and queue item with the chip and controls: ar/en, light/dark, 130 %.
3. A11y: labels verbatim from the deck, chip announced as "Zaghlol's guess, not confirmed", hit targets and spacing measured in tests; RTL order mirrored.
4. No amount styling changed; hide amounts unaffected.
