## Description
Bug reported by the PO. On the Money tab the circle shows **«بنك»** because the initials are the first word of the account label (`account.label.split(' ').first` → "بنك" for «بنك مصر», kept whole because it's ≤ 4 characters). The add-card grid and the institution search use the first letter of the Arabic name (`monogram`), so most banks show «ب» or a blank circle.

## Technical details
- Add to each institution in the registry/catalog a **short code** (e.g. NBE, CIB, BM, QNB, AAIB, HSBC, ENBD, ADIB, InstaPay, VF Cash…) and a **brand colour** (+ readable text colour), per the badge rules in design doc 08. Logos stay off until OQ-09 clears; this is the monogram fallback.
- Arabic UI shows the same Latin short code (how Egyptians recognise banks) unless the design doc says otherwise; ignore generic words (بنك، البنك، مصرف، Bank) if a code is ever derived.
- One avatar everywhere: Money tab, card detail, add-card grid, institution search results, transaction rows, filters, scan results (`onboarding/scan_results.dart` has its own `_initials` — replace it).
- Contrast of text on brand colour ≥ 4.5:1 (pick white or ink per colour; test).

## Acceptance criteria
1. No surface shows «بنك», a lone «ب» or an empty circle for a known institution (widget test over every registry institution).
2. Same badge on all listed surfaces; unknown/custom institutions fall back to neutral initials from the user's label minus generic words.
3. Contrast test passes for every brand colour in light and dark.
4. ar/en goldens for Money tab, add-card grid and search; no hard-coded strings.
