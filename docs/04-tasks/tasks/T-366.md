## Goal
The signed sync `config` block carries the effective provider id as `values["llm.provider"]` only when that provider has both display names (host config `Llm:Providers:<id>:DisplayNameAr/En`, startup check). The `llm.provider_name.*` keys are retired. Response side only; BR-SYNC-03 request allow-list unchanged.
