## Description
The PO sees 250 MB under Settings, app storage, with no user data. Find what that is, measure the installed size on a device, fix what is ours, and give the PO a small installable build.

## Acceptance criteria
1. The report names the artifact behind the 250 MB and explains installed size = APK + oat + extracted libs + data copied at first run.
2. Installed size measured on the CI emulator for debug and release, before/after, in `docs/05-reviews/T-208-installed-size.md`.
3. Native libs are provably not stored twice (not extracted, stored uncompressed); enforced in CI.
4. No OCR engine or PDFium dropped (ADR-024).
5. An installable release arm64 artifact exists, debug-signed, named as not for the store; the README says which file to install.
6. Release CI builds stay green.

## Builder note (native-platform-engineer, 2026-11-22)
- **What it is:** the debug universal APK (278 MiB code; +143 MiB `kernel_blob.bin` copied to the data dir at first launch = about 421 MiB). Not release, not user data. Full table: `docs/05-reviews/T-208-installed-size.md`.
- **Packaging was already right:** `extractNativeLibs=false`, every `.so` Stored, no `/data/app/.../lib` extraction, no legacy packaging anywhere. Made explicit in Gradle and asserted in app-ci (fails on extractNativeLibs=true or a compressed `.so`).
- **Tessdata copy** (1.4 MiB after the first scan only) and ML Kit models: no duplicate worth removing. Rive (7.3 MiB, no `.riv` yet) is the one unused native lib; deferral is ADR-024 option F, a PO decision, not applied.
- **Sideload build:** release, `--split-per-abi --target-platform android-arm64` (plain `--target-platform android-arm64` left the armeabi-v7a AAR libs in: 84 MiB, split gives 65.9 MiB), debug key, dev backend, artifacts `zaghlol-devSms|devNoSms-release-arm64-sideload`. Expected installed about 70 MiB.
- Self-check: no data, concurrency, input or secret paths changed; the workflow has no upload key (it errors if one appears), job-level `contents: write` only on the measure job (publishes a text report to a branch). Not verified: an arm64 device (derived from x86_64 oat), release smoke run (as T-190).
