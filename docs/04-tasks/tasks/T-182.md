## Description
Verify `seatKeys` proofs (ECDSA P-256 over the shared message format) and compute the keyed hashes the seat service stores, so no raw public key is ever persisted or logged.

## Technical details
- **Parse:** `seatKeys` = array of `{publicKey, signature}`; `publicKey` X9.63 uncompressed P-256 point, 65 bytes, base64url without padding; `signature` IEEE P1363 `r‖s`, 64 bytes, base64url. Max keys per op: `verify` 1, `restore` 5, `signin` 5. Public keys must be **distinct** (repeat → validation failure). Point must be on the curve.
- **Message:** `"zaghlol-seat-v1" ‖ 0x00 ‖ op ‖ 0x00 ‖ installId ‖ 0x00 ‖ challenge` with `installId` the lower-case UUID text from the **install token**; `challenge` 32 bytes (`verify`: SHA-256 of `signedTransaction`; `restore`: install-bound `bodyHash`; `signin`: SHA-256 of the raw nonce).
- **Result** per element: valid/invalid; the caller decides the HTTP outcome (restore/sign-in: invalid → `400 VALIDATION_FAILED`; verify: ignore).
- **Keyed hashes** through `IKeyedHasher` (T-123) with `K_seat`: `InstallKeyHash = HMAC-SHA256(K_seat, "install" ‖ 0x00 ‖ installId ‖ publicKey)`; `SeatKeyHash = HMAC-SHA256(K_seat, purchase_id ‖ publicKey)`; `digestOfPublicKeys = SHA-256(pk₀ ‖ … ‖ pkₙ₋₁)` (SHA-256 of the empty string when absent) for T-185's `clientDataHash`.
- **Element-0 helper:** `CheckElementZero(install, seatKeys) → Registered | MatchesRegistered | Mismatch` against `installs.seat_key_hash` (registration itself is done by the seat service, T-184, inside its transaction).
- **Fake** verifier/hasher for downstream tests. The redacting logger drops `seatKeys`; raw keys never leave this module except as hashes.

## Acceptance criteria
- [ ] Passes every vector in `backend/tests/Zaghlol.Contract.Tests/vectors/seat-proof-v1.json` (valid and invalid) through the production code path, not a test-local copy.
- [ ] Repeated public key, off-curve point, 64-byte (compressed or truncated) key, DER-encoded signature, and too many keys for the op are each rejected (tests).
- [ ] A signature made for another install ID, another `op`, or another challenge fails (tests).
- [ ] `InstallKeyHash` and `SeatKeyHash` for fixed inputs match test vectors computed with the fake key; the two never collide for the same public key (label separation test).
- [ ] `digestOfPublicKeys` reproduces `restore-binding-v1.json` `seatKeysDigestHex`.
- [ ] Log/trace sentinel test: no public key or signature appears.
- [ ] DoD (CLAUDE.md §7): analyze clean, formatted, tests added, no hard-coded strings, RTL verified where UI, no `double` money, no raw SMS in logs.
