## Description
Add flags `ask_llm`, `ask_llm_invest`, `llm_categorise` (off by default) to the closed `FlagKeys`. Implement the typed, range-checked closed key set over `remote_config` with defaults (incl. `ask.quota_free` 5, `ask.quota_gold` 50, `llm.spend_cap_usd` 10.00, `llm.provider`), edits through `PUT /admin/v1/config/{key}` (`flags_admin`, audited) and `zaghlol-ops config list|get|set`. `POST /v1/sync` adds a signed `config` block `{version, values}` (app-relevant keys + `llm.providerName` per language) when `configVersion` differs. `ILlmFeatureGate.IsOn(feature, install)` evaluates flags per request; switch `LlmProviderRegistry` to read `llm.provider`.

## Acceptance criteria
1. Unknown key → 404; out-of-range or wrong type → 400 `VALIDATION_FAILED`; every successful set writes an audit row and bumps `version`.
2. Sync returns the `config` block only when `configVersion` differs; the block is signed with the existing response-signing key and verifies with the existing app verifier vectors.
3. Server-only keys (`llm.spend_cap_usd`, `llm.provider`) are not sent to the app; `llm.providerName` is.
4. Changing `llm.provider` switches the active provider on the next request without restart (test with two fake providers).
5. Flag evaluation is per request, independent of any app-side cache (test: flag off → gate false on the next call).
6. `dotnet build -warnaserror`, `dotnet format`, unit tests green; OpenAPI matches T-322.
