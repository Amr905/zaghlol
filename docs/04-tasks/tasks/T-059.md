## Build notes
Compiled by agent from public sources; PO to spot-check. The sandbox had no web access (403), so the names come from the agent's knowledge and the source links in `docs/03-technical/merchant-sources.md` are unverified pointers. Result: 854 merchants (705 new, appended after the existing 149, ids unchanged), 2161 aliases, seed v1 re-signed with the dev key. The FU-256 seed upgrade adds the new rows to existing installs (hash-based, insert-only). Added aliases to Talabat and B.TECH for `TALABAT*ORDER` and `B.TECH SHOP`. The production signing key is untouched (PO item). Tests: `tools/catalog_build/test/catalog_build_test.dart` (count, aliases, one category per alias, sources coverage) and `app/test/features/categorization/data/seed_merchant_map_test.dart` (30 sample strings).
