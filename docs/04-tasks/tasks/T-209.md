## Description
Replace the Insights entry screen with the v2 layout: header with three tabs (Overview / Categories / Trends) and the period chip, then the Overview tab. Tabs 2 and 3 are built by T-210 / T-211; this task creates `presentation/v2/categories_tab.dart` and `presentation/v2/trends_tab.dart` as **minimal stubs** (a `CategoriesTab` / `TrendsTab` widget showing the "All charts" button) so the shell compiles; T-210 / T-211 replace those two files completely.

Overview cards, top to bottom:
1. **Hero pace card**: "Spent so far" number (primary currency), "Day N of M", a line vs the same days of the previous period, the projection to period end and the budget line (only when a budget exists); cumulative spending line for this period, the previous period as a thin grey line, budget as a dashed line, projection dashed from today. Press-and-drag scrubs the line (tooltip with day, spent to date and last period's figure at that day; `Charts2-2-pace-scrub`). Three small stats under it: income, left in budget (hidden when there is no budget), bills coming (sum of upcoming items to period end).
2. **Zaghlol line**: reuse the existing headline/explanation source; one or two sentences.
3. **Where it went**: top 4 categories as ranked horizontal bars with a grey tick at the previous period's same-days amount and a ▲/▼/= change; "See all categories" opens the Categories tab. Tapping a row opens the existing drill-down (`chart_drill.dart`).
4. **Saved each month**: last 6 months income minus spending as diverging bars (negative below the axis), current month projected (hatched), average line with label. Build it as a reusable widget (T-211 shows it again).
5. **Coming up**: next 3 subscriptions/bills/instalments with "in N days" and amount; hidden when none.
6. **All charts (12)** button opening the existing T-189 charts screen.

## Acceptance criteria
1. Insights opens on the Overview tab with the three tabs; the period picker applies to all tabs; the old charts screen is reachable from "All charts (12)" and is otherwise unchanged.
2. Pace maths in a pure domain function with unit tests: cumulative per day, same-days comparison against the previous period (shorter previous period: clamp to its last day), projection = spent ÷ elapsed days × period days in integer minor units (round half away from zero), budget line only when a budget exists. Closed (past) periods show the full line with no projection.
3. Money is integer minor units per currency; the hero uses the primary currency; other currencies spent in the period are listed under the hero in their own currency, never summed (D-28/D-29). No `double` for money (chart geometry may use doubles).
4. Gates per CHARTS-V2: hero and Coming up free; the other cards follow `chart_gate.dart` for the chart they come from, with the existing locked treatment for free users.
5. Hide amounts: every amount, axis label and tooltip figure shows the mask; percentages and day counts stay (`Charts2-7-hidden`).
6. Thin data (fewer than 3 days of data or no previous period): the hero shows the number and a short "not enough data yet" line instead of the comparison; empty Coming up is hidden; no crash with zero transactions.
7. RTL and LTR, light and True Black dark; Arabic-Indic digits per the digits setting; all strings in ARB + copy deck (Egyptian colloquial, «شهر» for the period); semantics labels on each chart give the key numbers.
8. Widget tests for the tabs, hero, scrub tooltip, category rows and saved bars; goldens (ar/en × light/dark + hidden) for the Overview tab. Goldens are generated by the CI `app-regen` workflow, not locally.
9. `dart analyze` clean (riverpod_lint), `dart format`, all insights tests green.
