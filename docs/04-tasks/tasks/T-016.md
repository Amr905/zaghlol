## Description
Encrypted Drift database that every repository builds on.

## Technical details
NativeDatabase.createInBackground with sqlite3mc; setup: PRAGMA cipher/legacy/key, verify cipher active else refuse; WAL, foreign_keys; schemaVersion 1; drift_dev schema dump folder; generated migration tests; pre-migration encrypted copy and restore-on-failure; DB file in no-backup dir.

## Design note
Required — solution-architect (Opus) writes it before implementation (C4).

## Acceptance criteria
- [ ] Opening with wrong key fails cleanly
- [ ] File header is not 'SQLite format 3'
- [ ] Migration failure restores the copy
- [ ] DoD (CLAUDE.md §7): analyze clean, formatted, tests added, no hard-coded strings, RTL verified where UI, no `double` money, no raw SMS in logs.
