## Design note
Sprint mode: the builder wrote this short note (no separate architect pass).

1. **Flow.** Dart (`features/widgets_bridge`) watches the primary-currency `CycleOverview` (recomputed on every `TransactionsChanged` through `cycleDataVersionProvider`), `hide_amounts.widget`, app lock, language, digits and primary currency. After a 2 s debounce it builds a `WidgetSnapshot` of finished strings and sends it only if the visible content changed. Native stores it and redraws the widget. A new transaction therefore reaches the widget in a few seconds (AC: within a minute).
2. **Redaction is a Dart job.** Hidden or locked: `•••/day`, no amount digit and no currency in the snapshot; native never sees the number. The widget shows the primary currency only, never a sum.
3. **Storage.** Encrypted with the existing spool key (Keystore on Android; shared Keychain item on iOS), own AAD, atomic replace, directory excluded from backup (`noBackupFilesDir`; App Group `Library/Application Support`, T-165). Unreadable file reads as "nothing to show" and is never deleted by a read. No logging.
4. **Android.** Glance (`glance-appwidget` 1.1.1 + Compose compiler plugin 2.4.0 matching Kotlin), `SafeToSpendWidgetReceiver` (exported, `APPWIDGET_UPDATE` only), 2x2 resizable, `updatePeriodMillis=0`. **iOS.** WidgetKit extension `ZaghlolWidget` (systemSmall, `TimelineProvider` with one entry and `.never`; the app calls `reloadAllTimelines`), shares `SharedGroups`, `BackupExclusion`, `SpoolKeychain`, `SpoolCipher`, `WidgetSnapshotStore` with Runner; `.privacySensitive()` on the amount line.
5. **Not done (scope).** W-02 quick-add voice / lock-screen widget (Could): not built. The widget does not roll "days to payday" over at midnight by itself; the app re-publishes on its next foreground (residual; a midnight-aware timeline needs the cycle schedule natively, which would put budget logic in native code).
6. **Wiring left to the Lead after T-087 merges.** `widgetCopyProvider` has no default and `widgetBridgeWiringProvider` is not yet watched by the app shell (the ARB keys are on T-087's branch). Adapter: `WidgetCopy(perDay: l.commonUnitPerDay, daysToPayday: (c, f) => l.homeHeroDaysToPayday(c, f), setBudget: l.homeHeroSetBudget, openApp: l.widgetOpenZaghlol)` built with `lookupAppLocalizations(Locale(lang))`; then `ref.watch(widgetBridgeWiringProvider)` next to `cycleAppWiringProvider`. "Delete everything" should call `widgetSnapshotPublisherProvider.clear()`.

### Manual device test (Android and iOS)
1. Add the "Safe to spend" widget (Android: long-press home, Widgets, Zaghlol; iOS: Edit Home Screen, +, Zaghlol). Before first launch it shows nothing (Android) / the app name (iOS).
2. Open the app with a budget: widget shows e.g. `314.28 EGP/day` and `7 days to payday` in the app language (Arabic: Arabic-Indic digits, RTL).
3. Add a manual transaction: widget changes within a few seconds (limit: one minute).
4. Settings, hide amounts on widget: widget shows `•••/day`; turn off: amount returns.
5. App lock on, lock the app: widget shows `•••/day` until unlock.
6. No budget: "Set a budget"; tap the widget: app opens on Home (through the lock screen if locked).
7. Kill the app and reboot: widget still shows the last snapshot (iOS: after first unlock).
8. Backup check: Android `adb shell run-as <id> ls no_backup/widget` exists and `allowBackup=false` (CI asserts); iOS: widget directory has `isExcludedFromBackup` (unit test covers the call).
Results: not run on a device in this sprint session (no device); the unit tests and CI compile are the evidence so far.
