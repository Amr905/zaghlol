## Description
Aiven for PostgreSQL (free plan: 1 GB storage, 1 GB RAM, single node, max_connections 20 of which ~6 reserved; TLS required, `verify-full` needs the Aiven project CA certificate).

## Acceptance criteria
1. Connection strings support `SSL Mode=VerifyFull` with the CA given as a PEM setting (`Database:CaCertificatePem`) or file path; startup refuses in Production with `Disable`/`Prefer`/`Require` without verification.
2. Pool sizes configurable per role and defaulted for the free plan (API + embedded workers ≤ 10 connections total; migrator 1–2); documented budget against max_connections.
3. Role bootstrap runnable as `avnadmin` (no superuser): creates the api/worker/migrator/support roles exactly as `bootstrap-roles.sql` (NOSUPERUSER, NOBYPASSRLS…), sets passwords from parameters, and works on Aiven's PostgreSQL version; a script `deploy/db/aiven-bootstrap.sh` (psql) + docs.
4. Migrations run from the deploy workflow (T-206) as the migrator role; `db-platform` CI unaffected.
5. Backups: document Aiven free-plan backups/PITR and what we keep ourselves (a weekly `pg_dump` from GitHub Actions to an encrypted artifact or the PO's storage — optional, off by default); RPO/RTO stated honestly vs NFR.
6. Data location: Aiven region choice recorded for PDPL (CR-03).
