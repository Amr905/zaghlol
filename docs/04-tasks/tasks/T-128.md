## Description
One small signed daily call.

## Technical details
- Compose blocks only when changed (`null` otherwise); server-side 24 h throttle; BR-SYNC-04 filters (person names, digits, phones, IPAs, custom categories); `install_hash` HMAC through `IKeyedHasher`; `daily_active_counts` upsert; ≤ 2 KB when up to date; ≤ 50 contributions and ≤ 10 bank requests per call.
- **Signed throttle with echo (R4-2):** a sync inside the window returns **200**, signed, with only `serverTime`, `nextSyncNotBefore` and `timeNonce` (T-123 filter).
- Every sync 200 carries `timeNonce`. The `entitlement`, `accountToken` and `supportNotice` blocks are filled by T-132 through an `ISyncEntitlementBlock` extension point defined here (returns `null` until T-132 lands).
- `entitlementIssuedAt` is accepted and passed to that extension point (T-132 uses it as the R5-7 delivery proof).
