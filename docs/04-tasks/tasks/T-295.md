## Description
Consent sheet with the masked preview (the same `SentTextView` as the disclosure), Allow / Not now, read-only mode from S-71; implements `ConsentPrompter` (T-293) and stores consent through `LlmConsentStore`. "What I sent" collapsible block: placeholders as non-interactive chips («كارت ١» …), scrub tokens as hidden chips, never the map. S-71 group visible only while `ask_llm` is on: switch (on → sheet without preview, confirm/cancel; off → clear consent + snackbar), quota line, "What's sent?" button, `privacy_server_itemAskLlm` in the server-knows list.

## Acceptance criteria
1. Widget tests: Allow stores `{provider, v, at}`; Not now / drag / back store nothing; switch off clears consent; Cancel from the switch leaves it off.
2. Chips render per token kind; the block takes the direction of its first strong character; chips are bidi-isolated.
3. Goldens in ar and en, light and dark, at 100 % and 130 % (buttons stack at 130 %).
4. Screen reader: block is one node with `sent_textA11y`; toggle announces expanded/collapsed; all targets ≥ 48 dp.
5. Row hidden while the flag is off; quota line hidden while paused, "unknown" text before first contact.
