## Design

## Description
The Trends tab: an "In and out" card (last 6 months: spending as thin bars, income as a line with dots, the current month hatched as projected), then T-209's "Saved each month" widget, then a "Day by day" calendar heatmap for the selected period (one cell per day, a single-hue sequential scale with 5 steps, week rows starting Saturday, a less→more legend, and a caption naming the priciest weekday, reusing the weekday data in `chart_models.dart`). Tapping a day opens that day's transactions.

## Acceptance criteria
1. Months with no data show an empty slot, not zero-height bars that read as zero spending; the projected month uses the T-209 projection function.
2. Heatmap buckets come from a pure function (quantiles of the period's non-zero days, integer minor units) with unit tests; a zero day is the lightest cell; future days are outlined, not filled.
3. Week starts Saturday; RTL mirrors the grid; the priciest weekday caption is omitted when fewer than 2 weeks of data exist.
4. Gate follows the matching existing charts in `chart_gate.dart`; hide amounts masks amounts in tooltips and labels; RTL/LTR, light/dark, digits setting; strings in ARB + copy deck.
5. Widget tests; goldens ar/en × light/dark via `app-regen`.
6. `dart analyze` clean, `dart format`, insights tests green.
