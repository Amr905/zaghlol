## Description
Real app (debug, `dev` attestation proof), real encrypted DB with synthetic data, flag and config forced on through the sync fake. The fake backend is a Dart `HttpServer` inside the integration test (reachable from the app on the device), serving fixture replies and recording received bodies. Flows: (1) ar question → consent sheet with preview → Allow → answer with badge and "What I sent"; (2) the same in en; (3) quota exhausted reply → at-limit bubble, no further request; (4) network off (fake server stopped / connectivity override) → needs-internet bubble, nothing sent later.

## Acceptance criteria
1. All four flows pass on `ci/T-298` (device-flows job), run id reported.
2. Recorded bodies contain only the FR-LLM-02 fields, and `q` equals the expected masked text.
3. Screenshots of each flow in ar and en published under `device-shots/<sha>/ask-llm/`.
4. Logs contain no question text.
